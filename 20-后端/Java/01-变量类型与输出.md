# 第 01 节　从零读写 Java：变量、类型与输出

假设小林领了 5 项任务，完成了 2 项。你当然可以自己算出 3，再让电脑打印「小林：剩余 3 项」。可明天完成数变了，你还得重新算、重新改文字。这一章要解决的是：**只告诉程序原始数据，让它自己算、自己说出结果。** 不需要会 TypeScript，不用建工程，也不用先学编译原理。

## 先认清地图：学变量，其实在回答三个问题

| 问题                | 例子                              | 本章怎么学               |
| ----------------- | ------------------------------- | ------------------- |
| 怎么给一个值起名字，再用这个名字？ | 把 `5` 记作 `assigned`，需要时取出来      | 先亲手做声明、初始化、读取、重新赋值  |
| 这个名字允许记什么值？       | 数量是整数，姓名是文本，是否完成是真或假            | 认识基本类型和引用类型，再练选型    |
| 这个名字在哪里有效，数据属于谁？  | 临时的计算结果、传给方法的数量、某个成员的姓名、团队共用的名称 | 对比局部变量、参数、实例字段和静态字段 |

后两行说的是**两个维度，不是同一张分类表**。例如，一名成员的任务数可以既是 `int`（能存什么），又是实例字段（属于哪个成员）。第一次读不用背表：先做到「打印任务摘要」；休息后再做「两个成员」的实验，看同一种类型怎样用在不同位置。

## 1　先让电脑打印一个数

准备 JDK 21（Java 开发工具包）和文本编辑器即可。在一个空文件夹里打开 PowerShell，输入 `java -version`。看到版本号 21 就可以继续；如果提示找不到 `java`，先安装 JDK 21，重开终端再检查。**终端里输入的是运行命令，编辑器里写的才是 Java 代码。**

在这个文件夹中新建 `TaskSummary.java`，以 UTF-8 保存下面的完整内容。注意扩展名不是 `.java.txt`。

```java
class TaskSummary {
    public static void main(String[] args) {
        System.out.println(3);
    }
}
```

回到同一目录的终端，输入 `java TaskSummary.java`，按回车。预期屏幕出现一行 `3`。把代码里的 `3` 改成 `8`，**保存，再运行同一条命令**。看到 `8`，才说明你运行的是刚编辑的文件。若提示找不到文件，先输入 `Get-ChildItem -Name`，确认当前目录里确实有这个文件。

这五行分成三层。最外面的 `class TaskSummary { … }` 给这段程序一个类名；里面的 `main` 是程序从哪里开始执行的约定。`public` 表示可公开访问，`static` 让启动时不用先创建对象，`void` 表示这个方法不交回结果；`String[] args` 接收命令行传来的文本参数，本例没有用它。**现在保持这两层不变就行。** 真正让屏幕变化的是最里面的 `System.out.println(3);`：`System.out` 是标准输出，`println` 是“打印后换行”，括号里放要打印的内容，分号表示这条语句结束。花括号 `{ }` 则标出一组代码的起止。

**以下短代码怎么用：**除非标明“完整文件”，每个 Java 代码块都是一个独立实验：用它替换 `main` 两个花括号之间的内容，不要把不同实验一直追加在一起。每次都保存，再执行 `java TaskSummary.java`。

## 2　从直接打印一个数，到给这个数起名字

```java
int assigned = 5;
System.out.println(assigned);
```

预期只打印一行 `5`，不是两行。第一行不负责显示任何东西。把它拆开读：`int` 是**类型**，这里表示整数；`assigned` 是**变量名**，由我们取，表示已分配的任务数；`5` 是直接写在源码里的**值**，这种写法叫字面量。= 是赋值：算出右边的值，存入左边的变量。第二行才读取这个变量当前的值并打印。

**声明、初始化、读取、重新赋值不是一回事。** 把刚才的两行换成下面的五行。运行前先猜：第二次赋值会不会把屏幕上已经打印出来的数字也改掉？

```java
int assigned;
assigned = 5;
System.out.println(assigned);
assigned = assigned + 2;
System.out.println(assigned);
```

| 执行到哪里 | `assigned` 此刻的状态 | 屏幕新增什么 |
| --- | --- | --- |
| `int assigned;` | 名字和类型已经声明，局部变量还没有可读取的值 | 无 |
| `assigned = 5;` | 第一次给值，得到 5 | 无 |
| 第一次 `println` | 读取 5，不改变它 | `5` |
| `assigned = assigned + 2;` | 先读右边的旧值 5，加 2 得 7，再把 7 存回左边 | 无 |
| 第二次 `println` | 读取 7 | `7` |

`int assigned = 5;` 就是声明时顺便初始化。以后改值只写 `assigned = 7;`，不是再写一次 `int assigned`。变量名区分大小写，`assigned` 和 `Assigned` 是两个名字；多个单词通常写成 `finishedCount`。别用 `int`、`class` 这样的语言关键字作名字。

## 3　变量能存什么：先看类型，再选写法

Java 把类型分成**基本类型**和**引用类型**。基本类型只有下面 8 种，`String` 不在其中。先会选，再记范围：普通任务数量优先 `int`，带小数的近似测量值通常用 `double`，真假用 `boolean`，姓名用 `String`。

| 基本类型      | 表示什么                               | 写法与选择理由                                                                         |
| --------- | ---------------------------------- | ------------------------------------------------------------------------------- |
| `byte`    | 8 位有符号整数，−128 到 127                | `byte level = 3;`。适合已规定为一个字节的数据；128 就装不下。                                       |
| `short`   | 16 位有符号整数，−32768 到 32767           | `short offset = 300;`。范围比 `byte` 大；普通计数不必特意选它。                                  |
| `int`     | 32 位有符号整数，−2147483648 到 2147483647 | `int assigned = 5;`。没有小数且范围足够时的常用选择。                                            |
| `long`    | 64 位有符号整数                          | `long total = 3_000_000_000L;`。30 亿超出 `int`；末尾大写 `L` 告诉 Java 这是长整数字面量，下划线只方便读数。 |
| `float`   | 32 位浮点数，约 6～7 位十进制有效数字             | `float hours = 1.5F;`。`F` 表示按 `float` 写，常用于明确要求该类型的场合。                          |
| `double`  | 64 位浮点数，约 15～16 位十进制有效数字           | `double hours = 1.5;`。小数字面量默认是 `double`。浮点数是近似表示，不宜直接拿它做要求十进制精确的金额计算。           |
| `char`    | 一个 16 位 UTF-16 代码单元                | `char grade = 'A';`。用单引号；不是任意一段文字，一个 emoji 也不一定装得进一个 `char`。                    |
| `boolean` | 只有 `true` 和 `false` 两个值            | `boolean done = false;`。写的是不带引号的真假，不是数字 0、1，也不是文本 `"false"`。                    |

为什么整数还要分四种？“整数”说的是值没有小数，“8 位、32 位”说的是拿多少个二进制位表示它。位数不同，能表示的范围就不同。类型也影响计算：试试 `System.out.println(5 / 2);`，输出是 `2`，因为两个整数做的是整数除法；只把 `5` 改成 `5.0`，结果就变成 `2.5`。不是打印时丢了小数，而是打印**之前**就已算出了不同结果。

**引用类型怎么理解？** `String member = "小林";` 表示变量 `member` 引用一个内容为“小林”的字符串对象。变量里保存的是通向对象的引用，而不是把整个对象复制进变量。字符串、数组（如 `int[]`）和自己定义的类都属于引用类型。引用还可以是 `null`，表示目前不指向任何对象；它和空字符串 `""` 不同，也不能赋给 `int`。稍后用两个成员亲眼看一次“两个名字指向同一对象”。

**特别容易看混的四个写法：** `3` 是整数；`'3'` 是一个字符；`"3"` 是文本；`"assigned"` 也是文本，不会去读取变量。试着只给 `println(assigned)` 里的名字加双引号：打印结果从 `5`（假设当前值为 5）变成 `assigned`。引号不是装饰，它改变了这段代码的意思。

## 4　把三个小步骤连起来：打印任务摘要

先只计算，不写文案：

```java
int assigned = 5;
int finished = 2;
int remaining = assigned - finished;
System.out.println(remaining);
```

运行结果是 `3`。第三行先取出 5 和 2，相减，再把结果存入一个**新变量** `remaining`。它保存的是这一次算出的值，不是一个会自动刷新的公式。如果在第三行之后加 `finished = 4;`，最后仍打印 `3`；把同一行移动到计算之前，才会打印 `1`。这就是为什么代码的先后顺序重要。

现在才加姓名和文案。下面是可以直接核对的**完整 `TaskSummary.java`**：

```java
class TaskSummary {
    public static void main(String[] args) {
        String member = "小林";
        int assigned = 5;
        int finished = 2;
        int remaining = assigned - finished;
        System.out.println(member + "：剩余 " + remaining + " 项");
    }
}
```

预期打印 `小林：剩余 3 项`。这里 `+` 遇到字符串是在**拼接文本**，不会去做减法。对比 `"剩余 " + 1 + 2` 和 `"剩余 " + (1 + 2)`：前者从左往右，先得到 `"剩余 1"`，再拼成 `"剩余 12"`；后者先算括号里的加法，得到 `"剩余 3"`。初学时先把数算好、再写输出，最不容易混。

## 5　变量写在哪里：为什么有的各管各的，有的大家共用？

前面写在 `main` 里的 `remaining` 是局部变量。从另一个方法里直接写这个名字，Java 并不知道你指的是谁。要理解原因，先区分两件事：**作用域**是“在哪段代码里可以使用这个名字”；**归属**是“这个值是某次调用临时用的、某个对象自己的，还是一个类共享的”。入门先认识这四种常见的位置：

| 写在哪里                 | 通常叫什么     | 谁提供初始值，谁能用                          |
| -------------------- | --------- | ----------------------------------- |
| 方法里面的代码块中            | 局部变量      | 自己赋值后才能读；从声明处到所在块末尾可见。另一次调用不是上次那一份。 |
| 方法声明的参数括号中           | 方法参数      | 调用时由传入的值初始化；在这次方法执行中使用。             |
| 类里面、方法外面，没有 `static` | 实例字段      | 每个对象有自己一份；要区分读的是哪个对象的字段。            |
| 类里面、方法外面，带 `static`  | 静态字段（类变量） | 属于类，同一个类的对象共享；用类名访问最清楚。             |

**用一个实验把区别看出来。** 保留刚才的文件，另建完整文件 `MemberDemo.java`。这里的“类”可以先理解为成员的定义，“对象”则是按定义创建出来的一个具体成员。`new MemberDemo()` 每执行一次，就创建一个新成员；点号表示访问指定对象或类里的内容。

```java
class MemberDemo {
    String name;
    static String team = "后端组";

    void report(int assigned) {
        int remaining = assigned - 1;
        System.out.println(name + " / " + team + " / " + remaining);
    }

    public static void main(String[] args) {
        MemberDemo first = new MemberDemo();
        MemberDemo second = new MemberDemo();
        first.name = "小林";
        second.name = "小周";
        first.report(5);
        MemberDemo.team = "平台组";
        second.report(3);
        first.report(5);
    }
}
```

运行 `java MemberDemo.java`。这里假设每次报告都扣掉一项已完成任务。预期三行：

```text
小林 / 后端组 / 4
小周 / 平台组 / 2
小林 / 平台组 / 4
```

顺着第一次调用读：`first.report(5)` 的意思是“请第一个成员，用 5 做一次报告”。`5` 交给参数 `assigned`；进入方法后才创建局部变量 `remaining` 并算出 4。方法里的 `name` 读的是发起这次调用的成员的字段，所以是小林。第二次调用换了对象、换了参数，结果是小周和 2。第三次再请小林报告，他的名字没变，组名却变了：**改 `first.name` 只会改一个成员，改 `MemberDemo.team` 改的是同一份共享数据。**

再做两个只改一处的实验，每做完一个就恢复：

- 把 `second = new MemberDemo()` 中的 `new MemberDemo()` 换成 `first`。这次没有创建第二个对象，只复制了一份引用；`second.name = "小周"` 改的正是 `first` 指向的那个成员。预测第一行姓名，然后运行核对。
- 只删掉 `first.name = "小林";`。第一次报告会显示 `null`。字段没有显式赋值时有默认值：数值字段为零，`boolean` 为 `false`，`char` 为编码值零，引用字段为 `null`。**局部变量没有同样的待遇**：把 `report` 里的计算改成只有声明 `int remaining;`，再尝试打印它，程序会拒绝运行，因为它可能尚未赋值。

**两个容易当成“新类型”的词。** `final int limit = 5;` 中的类型仍是 `int`，`final` 表示这个变量只能赋值一次，再写 `limit = 6;` 就会报错。对于引用，不能重新赋值不等于对象内部不能改。`var count = 5;` 则让 Java 从初始值推断局部变量为 `int`，并不表示类型可以随时换；后面写 `count = "五";` 仍然不行。不确定该选哪种类型时，先写明类型，把理由说清楚。

## 6　遇到错误，从哪儿查？

回到 `TaskSummary.java` 的完整示例。一次只制造一个错误，保存并运行，读完提示再恢复；否则后面的错误可能只是前一个错误引起的。

| 只改这一处 | 观察什么 | 原因与恢复方法 |
| --- | --- | --- |
| 把 `int finished = 2;` 改为 `int finished = "2";` | 报错位置指向赋值，程序还没打印摘要 | 右边是字符串，左边要求整数。要记数量就去掉引号。 |
| 把最后一行里的 `remaining` 改为 `Remaining` | 提示找不到这个名字 | Java 区分大小写。对照声明处恢复原拼写。 |
| 把减号换成加号 | 程序正常运行，却打印剩余 7 项 | 两种运算对整数都合法。语法没错不代表答案正确，要用手算结果核对。 |

## 7　关掉示例，检查自己能不能写出来

1. **选类型。** 给“成员姓名、剩余任务数、是否已完成、累计 30 亿条记录”各选一个类型。再回答：仅知道一个变量是 `int`，能不能判断它是局部变量还是字段？
2. **预测再验证。** 已知 `int assigned = 5;`，下一行把它赋给 `int snapshot = assigned;`，然后执行 `assigned = 8;`。分别打印两个变量，各是多少？为什么结果不同于两个名字指向同一个成员的实验？
3. **从空白完成。** 小林原有 5 项，今天新领 2 项，完成 4 项。只把这三个原始数量和姓名写进程序，不把答案写进文案。第一次预期打印 `小林：剩余 3 项`；只把今天新领的数量改成 0，再运行应为 `小林：剩余 1 项`。卡住时先不拼文字，只打印算出的整数；数字正确以后再加姓名。

**做完再核对：**第 1 题依次可选 `String`、`int`、`boolean`、`long`；类型不能告诉你声明位置。第 2 题 `assigned` 是 8，`snapshot` 仍是 5，因为赋值时复制的是当时那个整数；成员实验中复制的是引用。第 3 题的关键是先算“原有 + 新领 − 完成”，而不是改两次输出语句。

能自己写出摘要，并能解释“为什么改变输入会改变这行输出”，就可以进入 [[20-后端/Java/02-分支循环与方法|第 02 节：分支、循环与方法]]。8 种基本类型的精确范围不必背熟，有需要再回来查。
