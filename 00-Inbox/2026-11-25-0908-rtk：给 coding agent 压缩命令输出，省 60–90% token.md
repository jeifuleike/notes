# rtk：给 coding agent 压缩命令输出，省 60–90% token

## 内容

`brew install rtk`（Windows 用 `winget install rtk-ai.rtk`），再运行 `rtk init -g` 接入 Claude Code；之后 agent 读到的是 3 行摘要而非 40 行日志，长测试、构建、diff 场景最省，`rtk gain` 可看节省。[GitHub](https://github.com/rtk-ai/rtk)

## 怎么用

在日报里点开原文，按项目文档安装/试用；先在一个小工作流验证，再决定是否接入。

## 优化什么工作

工具调研、信息筛选和日常工作流自动化。
