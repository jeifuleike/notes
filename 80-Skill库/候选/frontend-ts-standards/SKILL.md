# 前端 TypeScript 开发规范

先确认需求的实际入口、仓库已有写法、调用方和验证方式。按本次变更选读[前端 TypeScript 编码与文件规范](references/frontend-typescript.md)。该文档可独立用于团队约定或代码审查。

- 新建或移动文件时，先确定谁使用它、谁会一起修改它，再选择目录和名称。
- 改现有实现时，沿输入、数据转换、状态写入和界面反馈追踪一条真实调用链。保留原有空值、错误、取消与清理语义。
- 审查时给出会触发问题的操作、受影响的行为和可验证的修改建议。目录示例按目标仓库约定取舍。
- 交付时说明哪些入口已经检查，列出实际运行的验证及仍缺的证据。只做分析时，提供建议和可核对的位置。
