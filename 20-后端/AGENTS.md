# 后端笔记维护约定

- 本目录为后端通用知识的正文来源，新增前先搜索已有主题，优先补充和合并。
- `00-后端学习导航.md` 为入口。知识直接放在 `Node基础/`、`Express与工程化/`、`数据库/`、`认证与安全/`，实践与历史进度放在 `实践/` 下对应项目或主题。
- 文件夹不加分类前缀或数字序号；文件保留由浅到深的两位序号，00 为导航。
- 库内使用带 vault 相对路径的 Obsidian 双链，跨仓库使用同盘相对路径链接（notes 位于 D:/notes，学习项目位于 D:/node/node-backend-study）；不要在 Markdown 链接中使用裸 D:/ 路径，以免被 VS Code 当作相对路径。
- 独立 node-backend-study 仓库维护代码、章节 TODO、接口和验收，不复制整章实践说明到知识笔记。
- 保留独有示例、个人背景和历史记录；历史状态注明历史性质，不据概念出现就判断已完成。
- 移动或重命名后检查双链、Markdown、图片及跨仓库引用，不依赖 Obsidian 自动处理脚本变更。
