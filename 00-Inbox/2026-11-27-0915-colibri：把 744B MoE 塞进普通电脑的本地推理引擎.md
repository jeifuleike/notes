# colibri：把 744B MoE 塞进普通电脑的本地推理引擎

## 内容

`git clone https://github.com/JustVugg/colibri && cd colibri && ./start-here.sh`，装好后 `./coli chat` 即可对话；它把热专家放 GPU/内存、冷专家从 NVMe 流式读取，GLM-5.2 744B int4 常驻约 9.9GB，适合在没独显或小显存机器上跑前沿开源模型。 [GitHub](https://github.com/JustVugg/colibri)
