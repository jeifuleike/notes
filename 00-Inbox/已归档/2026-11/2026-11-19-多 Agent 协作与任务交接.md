# 多 Agent 协作与任务交接

在已允许协作的工作里，先判断拆分是否有收益，形成可分派的任务表与验收责任。

示例把接口、列表和浏览器回归分给不同写入者；同一交互的模板、状态和逻辑由一个实现者负责。
