# Express 统一异常处理与工程化

## 1. 为什么不能到处 `try/catch`

如果每个 Controller 都写：

```ts
try {
  ...
} catch (error) {
  ...
}
```

会造成：

```text
重复代码
错误格式不统一
HTTP Status 不统一
业务错误难维护
```

正确思路：

```text
Service
↓
抛业务异常

Controller
↓
不负责兜底

Global Error Middleware
↓
统一转换成 HTTP Response
```

## 2. AppError

```ts
export class AppError extends Error {
  constructor(
    public readonly statusCode: number,
    public readonly code: string,
    message: string,
  ) {
    super(message)

    this.name = 'AppError'
  }
}
```

使用：

```ts
throw new AppError(
  404,
  'USER_NOT_FOUND',
  'User not found',
)
```

---

## 3. 为什么同时需要 statusCode / code / message

```text
statusCode
→ HTTP 标准语义

code
→ 前端 / 程序判断

message
→ 给人看的文本
```

例如：

```json
{
  "code": "USER_NOT_FOUND",
  "message": "User not found"
}
```

前端应该判断：

```ts
if (
  error.code ===
  'USER_NOT_FOUND'
) {
  ...
}
```

而不是：

```ts
if (
  error.message ===
  'User not found'
) {
  ...
}
```

因为 message 会改文案、语言。

## 4. Global Error Middleware

```ts
import type {
  ErrorRequestHandler,
} from 'express'

export const errorHandler:
  ErrorRequestHandler =
(
  error,
  req,
  res,
  next,
) => {
  console.error(error)

  if (error instanceof AppError) {
    res
      .status(error.statusCode)
      .json({
        code: error.code,
        message: error.message,
      })

    return
  }

  res.status(500).json({
    code: 'INTERNAL_SERVER_ERROR',
    message:
      'Internal Server Error',
  })
}
```

---

## 5. Error Middleware 要放最后

```ts
app.use(express.json())

app.use('/users', userRouter)

app.use(notFoundHandler)

app.use(errorHandler)
```

原因：

```text
请求从前往后匹配
```

发生异常后：

```text
Express
↓
向后寻找 Error Middleware
```

## 6. Route 404

```ts
app.use((req, res) => {
  res.status(404).json({
    code: 'ROUTE_NOT_FOUND',
    message: 'Route not found',
  })
})
```

注意：

```text
用户不存在
```

和：

```text
路由不存在
```

不是一回事。

前者：

```text
GET /users/999
→ USER_NOT_FOUND
```

后者：

```text
GET /abc
→ ROUTE_NOT_FOUND
```

## 7. 不要把内部错误直接返回前端

错误：

```ts
res.status(500).json({
  message: error.message,
})
```

原因是内部错误可能暴露：

```text
SQL
数据库账号
文件路径
系统结构
第三方 API 信息
```

推荐：

服务端：

```ts
console.error(error)
```

前端：

```json
{
  "code": "INTERNAL_SERVER_ERROR",
  "message": "Internal Server Error"
}
```

## 8. 更具体的异常类

```ts
export class NotFoundError
  extends AppError {
  constructor(
    code: string,
    message: string,
  ) {
    super(404, code, message)
  }
}
```

使用：

```ts
throw new NotFoundError(
  'USER_NOT_FOUND',
  'User not found',
)
```

还可以扩展：

```text
BadRequestError
UnauthorizedError
ForbiddenError
ConflictError
```
