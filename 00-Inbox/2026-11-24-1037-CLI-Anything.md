# CLI-Anything

## 内容

把没有 API 的软件包成 Agent 能调的 CLI：`pip install cli-anything-hub`，再运行 `cli-hub install 包名`；可为 QGIS、Blender、Inkscape 这类软件生成命令行封装。

## 怎么用

1. `pip install cli-anything-hub`；2. `cli-hub install <包名>` 装对应软件的封装（如 Blender、QGIS）；3. 让 coding agent 通过该 CLI 调软件做批量操作。

## 优化什么工作

让 agent 能调用只有图形界面的桌面软件，把设计、GIS 里的重复操作接进自动化流程。
