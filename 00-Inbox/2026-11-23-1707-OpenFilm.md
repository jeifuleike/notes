# OpenFilm

## 内容

把 coding agent 变成视频剪辑 Agent：`npx skills add openfilm/openfilm` 安装（需 Node 22.2+ 和 ffmpeg），或直接下载桌面端；可以边生成边手动调整时间线、字幕和画面。

## 为什么可能有用

做短视频或演示时可以先用 Agent 生成初剪，再手动微调时间线和字幕，减少剪辑里的机械操作。
