# 每日自律记录维护

- 工作日使用 `90-知识系统/模板/每日成长-任务时长模板.md`，休息日使用 `90-知识系统/模板/休息日-任务时长模板.md`；一篇只记录一天，不再创建双日周末模板。
- 两份模板末尾保留 indulgence_day 选项和 daily_summary。放纵日只需要日总结，其他字段均可跳过，不计为失败。
- 是否放纵必须来自明确选择或原文声明，不能根据玩游戏、任务未完成擅自补选。
- 历史双日记录按日期迁移任务；共享总结、心情等无法分日的数据保留来源标注，不平均分配或重复统计。
- 不丢弃历史原文、计划、实际分钟、评分；放纵日旧字段可折叠保留，不要求补齐。
- 周报读取 YAML 真实内容，忽略 INPUT 控件文本；与放纵日相关的未填字段不作零值，不纳入完成率分母。
- 模板保留 Obsidian Meta Bind 交互方式；没有证据不填日期、日类型或活动细节。已有空白未命名文件不猜日期。

- 表单不添加操作引导、填写示例或励志句；历史记录的来源和缺失说明保留。
- 成长与反思只保留 learning_growth（今天学到和成长，包含解决问题）与 issues_adjustments（未完成、原因、问题与调整）。
- 文末今日总结合并放纵日开关、daily_score 综合评分与 daily_summary 日总结；放纵日仅需日总结，评分可留空。
- 不再展示独立完成复盘、评分理由、值得肯定、最好的一件事或明日第一步。历史相关文字按含义合入新字段，原文存 legacy_review_fields 供追溯，周报不重复计数。

- 工作日表单不展示“今晚成长方向”及其独立选择、内容控件；历史内容归入学习成长并注明原安排性质，不将计划当作完成。

- 工作日实际时间记录由 DataviewJS 调用 `组件/时间记录` 共享视图；time_entries 每行 time、content，_id 用于稳定定位。时间面板先暂存小时与分钟，仅点确定才保存并关闭，取消不修改；支持添加与删除。旧 time_log 保留只读折叠，不能凭开始时间推算时长。

- 综合评分 daily_score 使用 0–10、步长 1 的 slider 滑块，与每日状态交互一致，不改成数字输入框；保留历史分数与空值。

- 休息日按全天规划：上午、下午、晚上分别最多两项任务（morning_N、afternoon_N、evening_N），生活与休息另列。历史没有时段的任务保留 goal_N 并显示在“时段未指定”，不猜时段。工作日表单不随休息日布局调整。

- 休息日“外出与社交”合并使用 outing_social_activity、outing_social_planned_minutes、outing_social_actual_minutes，不再分两张卡；旧时长可能重叠时不直接相加。

- 休息日不使用时间点控件，改用 activity_duration_log 记录活动和大约时长；不从旧时间点推算时长，与任务/生活卡片重复的活动只统计一次。

- growth-interactive 表单在阅读模式和实时预览中隐藏顶部属性面板，YAML 必须保留供交互控件读写，不通过删除属性来隐藏面板。

- 跨零点的睡前复盘按用户正在回顾的生活日归档，不直接套系统日期。此次复盘日是 2026-11-01，“昨天、今天”分别对应 2026-10-31、2026-11-01；不将本次内容写入 11 月 2 日。未来以用户明确的复盘日为准。

- 日报卡片按实际绑定字段是否有内容设置默认折叠：有有效文字、非零数值或已打开的开关则展开（[!growth-card]+），只有空值、默认 0、false 或“未选择”则折叠（[!growth-card]-）；time_entries 忽略空行的 _id。修改记录或模板时同步调整，不按放纵日一律折叠。

- 两份日报模板必须保留文末 `组件/卡片折叠` 共享视图，新建日报沿用；运行时监听当前笔记属性变化，有内容展开、清空折叠，手动打开空卡片时不立即强制收回。不能仅做一次静态批量更新。

- 周报不单列记录覆盖或数据说明；本周结论简洁列 1/2/3 点，新增证据评价与 AI 评分。评分按周总结规则分项加总，不混同日报自评分，不因放纵日留空或记录未知扣分。

- 今日总结包含 actual_sleep_time（实际睡觉时间，文本输入以支持约数和次日凌晨）。只依据明确实际描述回填，计划、上床、准备睡觉不当作实际入睡；没有明确描述留空。放纵日该项也可不填。

- 周复盘保留“本周数据”章节，按周总结规则核实任务、投入、娱乐、身体状态与实际睡觉时间；记录覆盖、数据说明独立章节不恢复；一段周记保留空白供用户编写。

- 周报“一段周记”和月报“一段月记”保留标题、正文留空，由用户自行编写；AI不生成内容或占位提示，不覆盖已经由用户写入的内容。

- 月报删除“数据说明与来源”独立章节，“客观评价与 AI 评分”位于空白“一段月记”之前，“一段月记”为整篇最后一节，AI不代写。评分按月内证据独立分项计算，不平均周报分数。

- 周报“本周收获”与月报“本月收获”具体整理实际做过、学过的事和非娱乐活动，覆盖项目、学习、整理、运动、生活等有记录主题；不只限于交付、不泛写成长、不编造未记录类别，月份边界保持严格。
