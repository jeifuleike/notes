# superpowers：把一整套开发方法论装进 coding agent

## 内容

`/plugin install superpowers@claude-plugins-official`（Claude Code）；装后自动先问清需求、写规格、列 TDD 计划，再用子代理逐项实现和复查，适合从零做功能或大重构，减少 agent 直接乱写。[GitHub](https://github.com/obra/superpowers)

## 怎么用

在日报里点开原文，按项目文档安装/试用；先在一个小工作流验证，再决定是否接入。

工具调研、信息筛选和日常工作流自动化。
