# dbx：25MB 的数据库客户端，内置 AI 与 MCP

## 内容

`brew install --cask dbx`（Windows 用 `winget install t8y2.dbx`），再运行 `dbx agent setup`；一个界面连 MySQL、PostgreSQL、SQLite、Redis、DuckDB 等 100+ 库，适合让 Agent 安全查库、跑分析 SQL。[GitHub](https://github.com/t8y2/dbx)
