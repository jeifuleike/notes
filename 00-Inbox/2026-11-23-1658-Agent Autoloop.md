# Agent Autoloop

## 内容

让 Claude Code、Codex 这类命令行 Agent 在后台自己接活，遇到拿不准的事把确认卡片推到钉钉、飞书、企微或 Slack。

## 为什么可能有用

适合把长任务放到后台跑，不用一直守着终端；钉钉卡片确认这一点和当前工作流很匹配。
