# Cloudflare security-audit-skill：把 Agent 变成安全审计员

## 内容

六阶段安全审计技能：侦察、覆盖式 hunting、候选验证、结构化输出、独立记录复核、目标无关报告；产出 findings.json、REPORT.md 等结构化结果，强调每个结论都有源码追踪。

## 为什么可能有用

适合发版前或接手陌生代码库时跑一遍，把“让 Agent 随便看看”变成有覆盖账本和复核的审计流程。
