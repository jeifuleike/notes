# MiniMind

## 内容

两小时从零训一个 64M 小模型：`git clone --depth 1 https://github.com/jingyaogong/minimind && cd minimind && pip install -r requirements.txt`；含预训练、SFT、LoRA、DPO、GRPO 全流程，单张 3090 跑完 SFT 一轮约 2 小时。

## 怎么用

1. clone 仓库并 `pip install -r requirements.txt`；2. 按 README 顺序跑 pretrain → SFT（可选 LoRA / DPO / GRPO）；3. 单张 3090 上 SFT 一轮约 2 小时，可在私有小数据上微调。

## 优化什么工作

想搞懂 LLM 训练全流程或在小数据上做私有微调时，一张 3090 就能跑通，适合教学和学习。
