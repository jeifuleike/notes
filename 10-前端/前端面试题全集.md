## 一、HTML 篇

### 1.1 DOCTYPE 的作用是什么？

**答案：**

`<!DOCTYPE>` 声明位于 HTML 文档的第一行，处于 `<html>` 标签之前，用于告诉浏览器使用哪种 HTML 或 DTD（文档类型定义）来解析文档。

```html
<!-- HTML5 -->
<!DOCTYPE html>

<!-- HTML 4.01 -->
<!DOCTYPE HTML PUBLIC "-//W3C//DTD HTML 4.01 Transitional//EN" "http://www.w3.org/TR/html4/loose.dtd">
```

**作用：**
- 触发浏览器的标准模式（Standards Mode）
- 如果不写，浏览器会使用怪异模式（Quirks Mode）渲染页面
- 标准模式和怪异模式的渲染方式不同，可能导致页面显示异常

### 1.2 什么是语义化标签？为什么要语义化？

**答案：**

语义化标签是指使用具有含义的 HTML 标签，如 `<header>`、`<nav>`、`<article>`、`<section>`、`<aside>`、`<footer>` 等。

**为什么要语义化：**

| 方面 | 说明 |
|------|------|
| **SEO 优化** | 搜索引擎能更好地理解页面结构，提升搜索排名 |
| **可访问性** | 屏幕阅读器能更准确地识别内容，方便盲人用户 |
| **代码可维护** | 其他开发者能更快理解代码结构 |
| **浏览器友好** | 某些浏览器样式需要语义化才能正常显示 |

**示例：**
```html
<!-- 非语义化 -->
<div class="header">
  <div class="nav">导航内容</div>
</div>
<div class="content">
  <div class="article">文章内容</div>
</div>

<!-- 语义化 -->
<header>
  <nav>导航内容</nav>
</header>
<main>
  <article>文章内容</article>
</main>
```

### 1.5 link 和 @import 的区别？

**答案：**

| 区别 | `<link>` | `@import` |
|------|----------|----------|
| **加载顺序** | 并行加载 | 串行加载（等前一个加载完才加载） |
| **DOM 控制** | 可用 JS 操作 | 不能操作 DOM |

**示例：**
```html

<!-- @import -->

  @import url("style.css");
</style>
```

## 二、CSS 篇

### 2.1 CSS 选择器优先级如何计算？

**答案：**

CSS 选择器的优先级由四个等级组成，权重计算公式：`a-b-c-d`

- **a**: ID 选择器的数量
- **b**: 类、属性、伪类选择器的数量
- **c**: 标签、伪元素选择器的数量
- **d**: 通配符、相邻选择器等的数量

**优先级从高到低：**

```
!important > 内联样式 > ID选择器 > 类/属性/伪类 > 标签/伪元素 > 通配符
```

**示例：**
```css
/* 权重计算 */
#header .nav li:first-child  /* a=1, b=1, c=2 -> 1-1-2 */
.nav .active::before         /* a=0, b=2, c=1 -> 0-2-1 */
.active                      /* a=0, b=1, c=0 -> 0-1-0 */
```

**注意：**
- `!important` 优先级最高，但应谨慎使用
- 同一优先级的选择器，后写的会覆盖先写的
- 伪类 `:not()` 不参与权重计算，但括号内的选择器参与

### 2.2 盒模型是什么？

**答案：**

CSS 盒模型是 CSS 布局的基础，每个 HTML 元素都被看作一个矩形盒子。

**两种盒模型：**

```css
/* 标准盒模型（默认） */
box-sizing: content-box;
/* width = content */

/* IE盒模型（怪异盒模型） */
box-sizing: border-box;
/* width = content + padding + border */
```

**盒模型的组成（从内到外）：**
1. **Content**：内容区域
2. **Padding**：内边距
3. **Border**：边框
4. **Margin**：外边距

### 2.3 BFC（块级格式化上下文）是什么？如何触发？

**答案：**

BFC 是 CSS 渲染模型的一块独立区域，内部的元素不会影响外部的元素布局。

**触发 BFC 的条件：**
- `overflow` 不为 `visible`（常用 `overflow: hidden`）
- `float` 不为 `none`
- `position` 为 `absolute` 或 `fixed`
- `display` 为 `inline-block`、`flex`、`grid`、`table` 等
- `display: flow-root`（最干净的触发方式）

**BFC 的特性和作用：**
1. 同一个 BFC 中，垂直方向的外边距会重叠
2. BFC 区域不会与浮动元素重叠
3. 计算 BFC 高度时，浮动元素也会参与计算
4. 每个 BFC 是独立的容器

**应用场景：**
```css
/* 清除浮动 */
.clearfix::after {
  content: '';
  display: block;
  clear: both;
}

/* 两栏自适应布局 */
.aside {
  float: left;
}
.content {
  overflow: hidden; /* 触发 BFC，不与浮动重叠 */
}
```

```css
  /* 简写 */
```

### 2.7 CSS 隐藏元素的方法及区别？

**答案：**

| 方法 | 占位 | 触发重排/重绘 | 事件绑定 | 可见性 |
|------|------|---------------|----------|--------|
| `display: none` | ❌ | ✅ 重排 | ❌ 不触发 | 不可见且不渲染 |
| `visibility: hidden` | ✅ | ❌ 重绘 | ❌ 不触发 | 不可见但渲染 |
| `opacity: 0` | ✅ | ❌ 重绘 | ✅ 触发 | 不可见但渲染 |
| `hidden` 属性 | ❌ | ✅ | ❌ | 同 display:none |

**区别详解：**

```css
/* 1. display: none */
.element {
  display: none;
  /* 完全从渲染树移除，不占任何空间 */
  /* 触发完整重排重绘 */
  /* 元素及其子元素的所有事件都不触发 */
}

/* 2. visibility: hidden */
.element {
  visibility: hidden;
  /* 仍占据空间 */
  /* 只触发重绘，不触发重排 */
  /* 元素及其子元素的所有事件都不触发 */
}

/* 3. opacity: 0 */
.element {
  opacity: 0;
  /* 占据空间 */
  /* 只触发重绘（GPU加速） */
  /* 子元素可以设置 opacity: 1 来覆盖 */
  /* transition 有效 */
}
```

### 3.1 var、let、const 的区别？

**答案：**

| 特性 | var | let | const |
|------|-----|-----|-------|
| 作用域 | 函数作用域 | 块级作用域 | 块级作用域 |
| 变量提升 | ✅ 声明提升，值为 undefined | ✅ 声明提升，但有暂时性死区 | ✅ 声明提升，但有暂时性死区 |
| 重复声明 | ✅ 允许 | ❌ 不允许 | ❌ 不允许 |
| 初始值 | 可选 | 可选 | 必须 |
| 修改值 | ✅ 可以 | ✅ 可以 | ❌ 不可以（对象/数组内部可修改） |

**详细说明：**

```javascript
// var 变量提升
console.log(a); // undefined（不是报错）
var a = 1;

// let 暂时性死区
console.log(b); // ReferenceError: Cannot access 'b' before initialization
let b = 2;

// 循环中的 var vs let
for (var i = 0; i < 3; i++) {
  setTimeout(() => console.log(i), 100); // 输出 3, 3, 3
}

for (let j = 0; j < 3; j++) {
  setTimeout(() => console.log(j), 100); // 输出 0, 1, 2
}

// const 对象
const obj = { a: 1 };
obj.a = 2; // ✅ 可以
obj = {};  // ❌ 不可以
```

### 3.2 什么是原型链？

**答案：**

原型链是 JavaScript 实现继承的机制，每个对象都有一个 `__proto__` 属性指向其原型对象，原型对象也有自己的原型，直到 `Object.prototype` 为止，形成一条链式结构。

```javascript
// 构造函数
function Person(name) {
  this.name = name;
}

Person.prototype.sayHello = function() {
  console.log(`Hello, I'm ${this.name}`);
};

const person = new Person('Alice');

// 实例属性
console.log(person.name);        // 'Alice'
console.log(person.__proto__);   // Person.prototype
console.log(person.__proto__.__proto__); // Object.prototype
console.log(person.__proto__.__proto__.__proto__); // null
```

**原型链继承：**
```javascript
function Animal(name) {
  this.name = name;
}

Animal.prototype.eat = function() {
  console.log(`${this.name} is eating`);
};

function Dog(name, breed) {
  Animal.call(this, name);
  this.breed = breed;
}

// 原型链继承
Dog.prototype = Object.create(Animal.prototype);
Dog.prototype.constructor = Dog;

const dog = new Dog('Buddy', 'Golden Retriever');
dog.eat(); // 继承自 Animal
```

### 3.3 什么是闭包？有什么应用场景？

**答案：**

**闭包是指函数能够访问其词法作用域外部的变量，即使这个函数在外部作用域之外执行。**

```javascript
function outer() {
  const a = 1;
  
  return function inner() {
    console.log(a); // 闭包：访问外部变量
  };
}

const fn = outer();
fn(); // 输出 1
```

**闭包的形成条件：**
1. 函数嵌套
2. 内部函数引用外部函数的变量
3. 内部函数在外部被引用

**应用场景：**

```javascript
// 1. 模块化
const module = (function() {
  let privateVar = '私有变量';
  
  return {
    getPrivate: () => privateVar,
    setPrivate: (val) => { privateVar = val; }
  };
})();

// 2. 防抖/节流
function debounce(fn, delay) {
  let timer = null;
  return function(...args) {
    clearTimeout(timer);
    timer = setTimeout(() => {
      fn.apply(this, args);
    }, delay);
  };
}

// 3. 缓存（记忆函数）
function memoize(fn) {
  const cache = {};
  return function(...args) {
    const key = JSON.stringify(args);
    if (cache[key]) return cache[key];
    return cache[key] = fn.apply(this, args);
  };
}

// 4. 私有变量
function createCounter() {
  let count = 0;
  return {
    increment: () => ++count,
    decrement: () => --count,
    getCount: () => count
  };
}
```

### 3.4 什么是 Event Loop（事件循环）？

**答案：**

JavaScript 是单线程语言，Event Loop 负责协调同步任务和异步任务的执行。

```javascript
console.log('1');

setTimeout(function() {
  console.log('2');
}, 0);

Promise.resolve().then(function() {
  console.log('3');
});

console.log('4');

// 输出顺序：1, 4, 3, 2
```

**Event Loop 执行顺序：**

```
1. 执行同步任务（调用栈）
2. 执行所有微任务（Microtasks）
   - Promise.then/catch/finally
   - queueMicrotask()
   - MutationObserver
3. 执行一个宏任务（Macrotask）
   - setTimeout
   - setInterval
   - setImmediate（Node）
   - I/O
   - UI Rendering
4. 重复步骤 2-3
```

**详细解释：**

```javascript
console.log('同步1');

setTimeout(() => {
  console.log('宏任务1');
  Promise.resolve().then(() => {
    console.log('微任务在宏任务中');
  });
}, 0);

Promise.resolve().then(() => {
  console.log('微任务1');
});

console.log('同步2');

// 输出：同步1 -> 同步2 -> 微任务1 -> 宏任务1 -> 微任务在宏任务中
```

### 3.5 什么是 Promise？有哪些方法？

**答案：**

Promise 是 ES6 引入的异步编程解决方案，用于处理异步操作。

**三种状态：**
- `pending`（进行中）
- `fulfilled`（已成功）
- `rejected`（已失败）

**基本用法：**
```javascript
const promise = new Promise((resolve, reject) => {
  // 异步操作
  if (success) {
    resolve(result);
  } else {
    reject(error);
  }
});

promise
  .then(result => console.log(result))
  .catch(error => console.error(error))
  .finally(() => console.log('完成'));
```

**Promise 静态方法：**

```javascript
// 1. Promise.resolve/reject
Promise.resolve(value);      // 返回成功的 Promise
Promise.reject(reason);      // 返回失败的 Promise

// 2. Promise.all - 所有都成功才成功
Promise.all([p1, p2, p3])
  .then(results => console.log(results));

// 3. Promise.allSettled - 不管成功失败都返回
Promise.allSettled([p1, p2, p3])
  .then(results => {
    results.forEach(result => {
      if (result.status === 'fulfilled') {
        console.log(result.value);
      } else {
        console.log(result.reason);
      }
    });
  });

// 4. Promise.race - 返回最快的一个
Promise.race([p1, p2, p3])
  .then(result => console.log(result));

// 5. Promise.any - 返回第一个成功的
Promise.any([p1, p2, p3])
  .then(result => console.log(result));
```

### 3.6 async/await 是什么？

**答案：**

async/await 是 ES2017 引入的异步编程语法糖，让异步代码看起来像同步代码。

**基本用法：**
```javascript
// async 函数总是返回 Promise
async function fetchData() {
  try {
    const response = await fetch('/api/data');
    const data = await response.json();
    return data;
  } catch (error) {
    console.error('Error:', error);
    throw error;
  }
}

// 使用
fetchData().then(data => console.log(data));
```

**执行顺序：**
```javascript
async function test() {
  console.log('1');
  await console.log('2');
  console.log('3'); // 这个在 await 之后执行
}

console.log('4');
test();
console.log('5');

// 输出：4, 1, 2, 5, 3
```

**并行执行：**
```javascript
// 串行（慢）
const data1 = await fetchData1();
const data2 = await fetchData2();

// 并行（快）
const [data1, data2] = await Promise.all([
  fetchData1(),
  fetchData2()
]);
```

### 3.8 深拷贝和浅拷贝？

**答案：**

**基本类型 vs 引用类型：**
```javascript
// 基本类型：值拷贝
let a = 1;
let b = a;  // b = 1
b = 2;      // a 不变

// 引用类型：引用拷贝
let obj1 = { name: 'Alice' };
let obj2 = obj1;  // obj2 指向同一个对象
obj2.name = 'Bob'; // obj1.name 也变了
```

**浅拷贝方法：**
```javascript
// 1. Object.assign
const obj2 = Object.assign({}, obj1);

// 2. 扩展运算符
const obj2 = { ...obj1 };

// 3. 数组：concat/slice/扩展运算符
const arr2 = [...arr1];
```

**深拷贝方法：**
```javascript
// 1. JSON.parse(JSON.stringify())
const deepCopy = JSON.parse(JSON.stringify(obj));
// 缺点：undefined、Symbol、函数会被忽略，无法拷贝循环引用

// 2. 手写递归深拷贝
function deepClone(obj, hash = new WeakMap()) {
  // 处理 null
  if (obj === null) return obj;
  
  // 处理基本类型
  if (typeof obj !== 'object') return obj;
  
  // 处理循环引用
  if (hash.has(obj)) return hash.get(obj);
  
  // 处理 Date
  if (obj instanceof Date) return new Date(obj);
  
  // 处理 RegExp
  if (obj instanceof RegExp) return new RegExp(obj);
  
  // 处理数组/对象
  const clone = Array.isArray(obj) ? [] : {};
  hash.set(obj, clone);
  
  for (const key in obj) {
    if (obj.hasOwnProperty(key)) {
      clone[key] = deepClone(obj[key], hash);
    }
  }
  
  return clone;
}

// 3. structuredClone（现代浏览器/Node）
const deepCopy = structuredClone(obj);
```

### 3.9 说说 this 的指向？

**答案：**

`this` 的指向取决于函数的调用方式：


### 3.10 什么是防抖和节流？

**答案：**

**防抖（Debounce）：事件触发 n 秒后才执行，n 秒内再次触发则重新计时**
```javascript
function debounce(fn, delay) {
  let timer = null;
  return function(...args) {
    clearTimeout(timer);
    timer = setTimeout(() => {
      fn.apply(this, args);
    }, delay);
  };
}

// 应用：搜索框输入、窗口调整大小
input.addEventListener('input', debounce(search, 500));
```

**节流（Throttle）：n 秒内只执行一次，稀释执行频率**
```javascript
function throttle(fn, delay) {
  let lastTime = 0;
  return function(...args) {
    const now = Date.now();
    if (now - lastTime >= delay) {
      lastTime = now;
      fn.apply(this, args);
    }
  };
}

// 应用：滚动加载、按钮防重复点击
window.addEventListener('scroll', throttle(handleScroll, 200));
```

### 9.4 浏览器缓存策略？

**答案：**

**缓存类型：**

|----------|----------|------|
| Service Worker | 浏览器 | 完全控制缓存逻辑 |
| Memory Cache | 内存 | 关闭标签页即消失 |
| Disk Cache | 磁盘 | 持久化存储 |
| Push Cache | HTTP/2 | 服务端推送缓存 |

**HTTP 缓存策略：**

`javascript
// 1. 强缓存（不发送请求）
//    - Expires（HTTP/1.0）：绝对时间
//    - Cache-Control（HTTP/1.1）：相对时间
//    优先级：Cache-Control > Expires

// Cache-Control 指令：
// no-cache：每次都验证
// no-store：不缓存
// public：可被任何缓存存储
// private：只有浏览器缓存
// max-age=3600：缓存有效期（秒）
// s-maxage=3600：代理服务器缓存有效期

// 2. 协商缓存（发送请求验证）
//    - Last-Modified / If-Modified-Since
//    - ETag / If-None-Match
//    优先级：ETag > Last-Modified

// Last-Modified 流程：
// 1. 服务器返回 Last-Modified: Wed, 21 Oct 2023 07:28:00 GMT
// 2. 浏览器缓存
// 3. 再次请求带上 If-Modified-Since: Wed, 21 Oct 2023 07:28:00 GMT
// 4. 服务器检查资源是否变化
// 5. 304 Not Modified（未变化）或 200 OK（已变化）

// ETag 流程：
// 1. 服务器返回 ETag: "33a64df551425fcc55e4d42a148795d9"
// 2. 浏览器缓存
// 3. 再次请求带上 If-None-Match: "33a64df551425fcc55e4d42a148795d9"
// 4. 服务器验证 ETag
// 5. 304 或 200
`

**缓存优先级：**
`
Memory Cache → Disk Cache → 网络请求 → Service Worker Cache

/**
 * 防抖函数
 * @param {Function} fn - 要执行的函数
 * @param {number} delay - 延迟时间（毫秒）
 * @param {boolean} immediate - 是否立即执行
 * @returns {Function}
 */
function debounce(fn, delay, immediate = false) {
  let timer = null;
  
  return function(...args) {
    const context = this;
    
    // 立即执行模式下，先清除之前的定时器
    if (timer) clearTimeout(timer);
    
    if (immediate && !timer) {
      fn.apply(context, args);
    }
    
    timer = setTimeout(() => {
      if (!immediate) {
        fn.apply(context, args);
      }
      timer = null;
    }, delay);
  };
}

### 12.2 实现节流函数

`javascript
/**
 * 节流函数
 * @param {Function} fn - 要执行的函数
 * @param {number} delay - 间隔时间（毫秒）
 * @param {Object} options - 配置项
 * @returns {Function}
 */
function throttle(fn, delay, options = {}) {
  let lastTime = 0;
  let timer = null;
  const { trailing = true, leading = true } = options;
  
  return function(...args) {
    const context = this;
    const now = Date.now();
    
    // 首次调用时判断是否立即执行
    if (!lastTime && !leading) lastTime = now;
    
    const remaining = delay - (now - lastTime);
    
    if (remaining <= 0 || remaining > delay) {
      // 超过了间隔时间，立即执行
      if (timer) {
        clearTimeout(timer);
        timer = null;
      }
      lastTime = now;
      fn.apply(context, args);
    } else if (!timer && trailing) {
      // 设置定时器，确保最后一次一定会执行
      timer = setTimeout(() => {
        lastTime = leading ? Date.now() : 0;
        timer = null;
        fn.apply(context, args);
      }, remaining);
    }
  };
}

// 使用示例
const throttledScroll = throttle(handleScroll, 200, { leading: true, trailing: true });
window.addEventListener('scroll', throttledScroll);
`

### 12.3 实现深拷贝

`javascript
/**
 * 深拷贝
 * @param {*} obj - 要拷贝的对象
 * @param {WeakMap} hash - 用于处理循环引用
 * @returns {*}
 */
function deepClone(obj, hash = new WeakMap()) {
  // 处理 null
  if (obj === null) return null;
  
  // 处理基本类型
  if (typeof obj !== 'object') return obj;
  
  // 处理日期
  if (obj instanceof Date) return new Date(obj);
  
  // 处理正则
  if (obj instanceof RegExp) return new RegExp(obj);
  
  // 处理函数（可选：深拷贝函数）
  if (typeof obj === 'function') return obj;
  
  // 处理循环引用
  if (hash.has(obj)) return hash.get(obj);
  
  // 处理数组和对象
  const clone = Array.isArray(obj) ? [] : {};
  hash.set(obj, clone);
  
  // 遍历所有属性
  for (const key in obj) {
    if (Object.prototype.hasOwnProperty.call(obj, key)) {
      clone[key] = deepClone(obj[key], hash);
    }
  }
  
  // 处理 Symbol 作为 key
  const symbolKeys = Object.getOwnPropertySymbols(obj);
  for (const sym of symbolKeys) {
    if (Object.prototype.hasOwnProperty.call(obj, sym)) {
      clone[sym] = deepClone(obj[sym], hash);
    }
  }
  
  return clone;
}

### 12.5 实现简易 Promise

`javascript
/**
 * 简易 Promise 实现
 */
class MyPromise {
  constructor(executor) {
    this.state = 'pending';
    this.value = undefined;
    this.callbacks = [];
    
    const resolve = (value) => {
      if (this.state !== 'pending') return;
      
      this.state = 'fulfilled';
      this.value = value;
      
      this.callbacks.forEach(cb => cb.onFulfilled(value));
    };
    
    const reject = (reason) => {
      if (this.state !== 'pending') return;
      
      this.state = 'rejected';
      this.value = reason;
      
      this.callbacks.forEach(cb => cb.onRejected(reason));
    };
    
    try {
      executor(resolve, reject);
    } catch (error) {
      reject(error);
    }
  }
  
  then(onFulfilled, onRejected) {
    return new MyPromise((resolve, reject) => {
      const handle = (callback, fallback) => {
        if (typeof callback === 'function') {
          try {
            const result = callback(this.value);
            resolve(result);
          } catch (error) {
            reject(error);
          }
        } else {
          fallback(this.value);
        }
      };
      
      if (this.state === 'fulfilled') {
        handle(onFulfilled, resolve);
      } else if (this.state === 'rejected') {
        handle(onRejected, reject);
      } else {
        this.callbacks.push({
          onFulfilled: () => handle(onFulfilled, resolve),
          onRejected: () => handle(onRejected, reject)
        });
      }
    });
  }
  
  catch(onRejected) {
    return this.then(null, onRejected);
  }
  
  finally(onFinally) {
    return this.then(
      value => MyPromise.resolve(onFinally()).then(() => value),
      reason => MyPromise.reject(onFinally()).then(() => { throw reason; })
    );
  }
  
  static resolve(value) {
    if (value instanceof MyPromise) return value;
    return new MyPromise(resolve => resolve(value));
  }
  
  static reject(reason) {
    return new MyPromise((_, reject) => reject(reason));
  }
  
  static all(promises) {
    return new MyPromise((resolve, reject) => {
      const results = [];
      let count = 0;
      
      promises.forEach((promise, index) => {
        MyPromise.resolve(promise).then(
          value => {
            results[index] = value;
            count++;
            if (count === promises.length) {
              resolve(results);
            }
          },
          reject
        );
      });
      
      if (promises.length === 0) resolve([]);
    });
  }
  
  static race(promises) {
    return new MyPromise((resolve, reject) => {
      promises.forEach(promise => {
        MyPromise.resolve(promise).then(resolve, reject);
      });
    });
  }
}

// 测试

  setTimeout(() => resolve('success'), 1000);
})
  .then(value => console.log(value))
  .catch(error => console.error(error));

      return fn(...args);
    }
    return function(...args2) {

    };
  };

  return function curried(...args) {

      .every(arg => arg !== PLACEHOLDER && arg !== undefined);

      return fn(...args.slice(0, fn.length));

function compose(...fns) {
  if (fns.length === 0) return arg => arg;
  if (fns.length === 1) return fns[0];
  
  return fns.reduce((acc, fn) => (...args) => acc(fn(...args)));
}

function pipe(...fns) {
  if (fns.length === 0) return arg => arg;
  if (fns.length === 1) return fns[0];
