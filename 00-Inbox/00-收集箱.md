# 收集箱

临时区只负责收集，不要求分类。处理前不改动正式笔记。

```dataview
TABLE status AS 状态, kind AS 类型, capture_reason AS 原因, captured AS 收集时间
FROM "00-Inbox"
WHERE type = "inbox"
SORT captured DESC
```

## 处理入口

- 对 Codex 说“整理临时区”，它会生成 `审核/` 下的报告。
- 批准后再说“执行 1、3”或“全部执行”。
- 原始资料处理完移到 `已归档/YYYY-MM/`。
