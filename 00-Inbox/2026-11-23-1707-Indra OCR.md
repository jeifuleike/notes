# Indra OCR

## 内容

CPU 上即可运行的轻量 OCR：`pip install indra-ocr` 安装，把 PDF/图片转成 Markdown、JSON 或带坐标文本，支持 80 多种语言和手写；官方称速度约为 Tesseract 的 15 倍，无需 GPU。

## 为什么可能有用

本地批量把 PDF、扫描件转成 Markdown 时不需要 GPU，适合接进知识库的文档入库与整理流程。
