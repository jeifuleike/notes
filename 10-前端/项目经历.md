# 项目经历

## 一、订单管理系统（order_vue）

### 项目概述

| 项目信息 | 详情 |
|---------|------|
| **项目名称** | 电商订单管理系统 |
| **项目类型** | B端管理系统 |
| **技术栈** | Vue 2.7 + Vuex + Vue Router + Element UI + TypeScript |
| **构建工具** | Vue CLI 5 + Webpack 5 |
| **包管理** | pnpm |

### 技术架构

**核心技术：**
- **框架**：Vue 2.7（支持 Composition API）
- **状态管理**：Vuex 3.5
- **路由**：Vue Router 3.x
- **UI 组件库**：Element UI 2.13
- **图表**：ECharts 5.4
- **工具库**：lodash-es、dayjs、big.js（精确计算）
- **HTTP 请求**：Axios
- **样式**：Less + Sass

**工程化配置：**
- TypeScript 类型支持
- ESLint + Prettier 代码规范
- Babel 转换
- px 转 rem 适配方案
- 自动导入配置（unplugin-auto-import）

### 功能模块

| 模块 | 功能描述 |
|------|----------|
| **订单管理** | 订单列表、订单详情、批量操作、订单筛选、快速下单 |
| **退款管理** | 退款申请、退款审核、退款列表、电子面单退款 |
| **发货管理** | 发货单管理、物流跟踪、自动发货配置 |
| **分销商管理** | 分销商列表、分销商授权、分销商设置 |
| **供应商管理** | 供应商列表、供应商授权、供应商商品管理 |
| **自动处理** | 自动下单、自动退款、自动发货规则配置 |
| **利润分析** | 利润统计、利润报表、利润趋势分析 |
| **私采管理** | 私采订单、私采审核 |
| **微信集成** | 微信授权、微信支付配置 |
| **系统设置** | 权限管理、用户管理、操作日志、通知设置 |

### 项目职责

1. **订单核心模块开发**
   - 实现订单列表的多条件筛选、分页加载
   - 开发批量操作功能（批量发货、批量退款、批量修改）
   - 实现订单详情页的信息展示和操作按钮联动

2. **退款流程开发**
   - 实现退款申请表单和退款审核流程
   - 开发退款列表的状态筛选和批量处理
   - 对接电子面单退款接口

3. **自动处理规则配置**
   - 开发自动下单规则配置页面
   - 实现自动退款规则的条件配置
   - 开发自动发货规则的物流模板配置

4. **性能优化**
   - 使用虚拟列表优化长列表渲染
   - 实现组件懒加载减少首屏加载时间
   - 优化 ECharts 图表渲染性能

### 项目亮点

- 使用 Vue 2.7 的 Composition API 重构部分复杂组件，提升代码可维护性
- 封装通用的表格组件，支持自定义列、筛选、排序、导出
- 实现权限指令和路由守卫，控制页面和按钮级别的权限
- 使用 big.js 处理金额计算，避免浮点数精度问题

## 二、浏览器插件系统（order_plugin）

### 项目概述

| 项目信息 | 详情 |
|---------|------|
| **项目名称** | 订单助手浏览器插件 |
| **项目类型** | Chrome Extension（支持 MV3） |
| **技术栈** | TypeScript + Vue 2.7 + Webpack 5 |
| **构建工具** | Webpack 5 + 自定义构建配置 |
| **包管理** | pnpm（monorepo 架构） |

### 技术架构

**核心技术：**
- **插件架构**：Chrome Extension Manifest V3
- **开发语言**：TypeScript 5.8
- **UI 框架**：Vue 2.7 + Element UI
- **数据存储**：Dexie（IndexedDB 封装）
- **加密**：crypto-js、JSEncrypt
- **工具库**：lodash-es、dayjs、big.js、RxJS

**工程化特性：**
- Monorepo 架构（packages 多包管理）
- TypeScript 类型生成工具（gen-types）
- Webpack 代码混淆（webpack-obfuscator）
- Jest 单元测试

### 项目结构

```
order_plugin/
├── packages/
│   ├── plugin-mv3/      # MV3 插件主体
│   ├── runtime/         # 运行时环境
│   ├── lib/             # 公共库
│   ├── const/           # 常量定义
│   ├── gen-types/       # 类型生成工具
│   └── @types/          # 类型声明
├── webpack.config/      # 构建配置
└── jest/                # 测试配置
```

### 功能模块

| 模块 | 功能描述 |
|------|----------|
| **订单抓取** | 从电商平台抓取订单数据 |
| **数据处理** | 订单数据解析、转换、校验 |
| **本地存储** | 使用 IndexedDB 存储订单数据 |
| **数据同步** | 与服务端同步订单数据 |
| **快捷操作** | 快捷键触发常用操作 |
| **弹窗界面** | Popup 弹窗展示订单概览 |
| **选项页面** | Options 页面配置插件设置 |

### 项目职责

1. **MV3 插件架构升级**
   - 将插件从 MV2 升级到 MV3
   - 适配 Service Worker 替代 Background Page
   - 处理 MV3 的 CSP 限制和远程代码执行限制

2. **订单抓取功能开发**
   - 使用 Content Script 注入电商页面
   - 实现多平台订单数据抓取适配器
   - 处理不同平台的数据格式差异

3. **数据存储与同步**
   - 使用 Dexie 封装 IndexedDB 操作
   - 实现离线数据存储和在线同步机制
   - 开发数据冲突处理策略

4. **构建优化**
   - 配置 Webpack 多入口构建
   - 实现代码混淆保护核心逻辑
   - 优化插件包体积

### 项目亮点

- 实现 Monorepo 架构，统一管理多个子包
- 使用 TypeScript 全栈类型安全
- 适配 Chrome MV3 最新标准
- 使用 IndexedDB 实现大量数据本地存储
- 实现多电商平台订单抓取适配器模式
