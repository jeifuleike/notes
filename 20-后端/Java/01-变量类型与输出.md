# 第 01 节　从零读写 Java：变量、类型与输出

本节从一个很小的任务统计开始：小林一共领取了 5 项任务，已经完成 2 项，程序需要算出还剩 3 项，并打印摘要。重点不是把答案 `3` 写死，而是把原始数据交给程序，让它根据数据计算结果。

学完本节，你应该能够：

- 独立创建并运行一个最简单的 Java 程序。
- 解释变量声明、初始化、赋值和读取的区别。
- 选择常见的 Java 基本类型，知道 `String` 为什么不是基本类型。
- 看懂整数除法、浮点数近似表示和基本类型转换。
- 区分局部变量、方法参数、实例字段和静态字段。
- 根据错误信息定位常见的类型、拼写和初始化问题。

本节只使用 JDK 21 和文本编辑器，不要求先安装 Maven，也不要求会 TypeScript。

## 先认清地图：变量其实在回答三个问题

| 问题 | 例子 | 对应知识 |
| --- | --- | --- |
| 怎样给一个值起名字？ | 把 `5` 记作 `assigned`，以后通过名字读取 | 变量声明、初始化、赋值 |
| 这个名字允许保存什么？ | 数量是整数，姓名是文本，是否完成是真或假 | 基本类型、引用类型 |
| 这个名字在哪里有效、数据属于谁？ | 临时计算结果、传入方法的数量、某个成员自己的姓名、团队共用名称 | 作用域、局部变量、参数、实例字段、静态字段 |

后两个问题是两个维度，不是一张分类表。例如 `int age` 中，`int` 说明它能保存什么类型的值；如果它写在类中、方法外面且没有 `static`，它又是一个实例字段，表示它属于某个对象。

## 准备环境：先确认 JDK 能运行

在一个空文件夹里打开 Windows PowerShell，执行：

```powershell
java -version
javac -version
```

本课程以 JDK 21 为基准。两条命令都应该能显示版本信息。`java` 是运行程序的启动命令，`javac` 是 Java 编译器；它们都由 JDK 提供。如果提示找不到命令，先安装 JDK 21，重新打开终端再检查。若两条命令显示的版本不一致，执行 `Get-Command java,javac` 查看它们分别来自哪个目录。

**终端里输入的是命令，编辑器里写的才是 Java 代码。** 本节先使用 Java 的源码启动模式：`java TaskSummary.java`。这适合刚开始的小实验，后续第 04 节会把编译和运行拆成两步。

## 1　先让电脑打印一个数

在当前文件夹新建 `TaskSummary.java`，使用 UTF-8 保存下面的完整内容。注意文件扩展名必须是 `.java`，不要变成 `.java.txt`。

```java
class TaskSummary {
    public static void main(String[] args) {
        System.out.println(3);
    }
}
```

回到 PowerShell，确认当前目录就是文件所在目录，然后运行：

```powershell
java TaskSummary.java
```

预期屏幕出现一行：

```text
3
```

把代码里的 `3` 改成 `8`，保存，再运行同一条命令。看到 `8`，才说明本次运行读取的是你刚刚保存的源码。

### 1.1 先看懂程序的外壳

```java
class TaskSummary {
    public static void main(String[] args) {
        System.out.println(3);
    }
}
```

- `class TaskSummary`：定义一个名为 `TaskSummary` 的类。Java 程序中的代码通常组织在类或接口等类型中。
- `{` 和 `}`：标记代码块的开始和结束。外层花括号属于类，内层花括号属于 `main` 方法。
- `public static void main(String[] args)`：Java 启动器约定识别的标准程序入口。`public` 表示公开访问，`static` 表示调用它不需要先创建 `TaskSummary` 对象，`void` 表示它不返回结果，`String[] args` 用来接收命令行参数。
- `System.out.println(3);`：向标准输出打印内容并换行。括号里是本次要打印的表达式，分号表示一条语句结束。

现在不需要自己改写 `main` 的完整声明，先把它当成程序入口的固定外壳。后面会逐渐拆解它。

### 1.2 `print`、`println` 和注释

`System.out` 表示标准输出。常见的两个方法是：

```java
System.out.print("小林");
System.out.print("还有 3 项");

System.out.println("小周");
System.out.println("还有 2 项");
```

`print` 打印后不自动换行，`println` 打印后换行。输出效果是：

```text
小林还有 3 项小周
还有 2 项
```

注释用于给人阅读，不会作为普通 Java 语句执行：

```java
// 单行注释：解释下一行或当前代码

/*
   多行注释：适合较长的说明
*/
```

注释不能代替代码本身的清晰命名。`// 计算剩余任务` 是说明；真正执行计算的仍然是后面的表达式。

## 2　从直接打印一个数，到给这个数起名字

先看两行：

```java
int assigned = 5;
System.out.println(assigned);
```

预期打印 `5`。第一行声明一个变量并初始化它，第二行读取变量当前的值并打印。

把第一行拆开：

- `int`：变量的类型，表示这里保存整数。
- `assigned`：变量名，由程序员取名。
- ` = `：赋值运算符，把右侧表达式计算出的值赋给左侧变量。
- `5`：直接写在源码中的值，叫作字面量。
- `;`：语句结束标记。

### 2.1 声明、初始化、读取、重新赋值

这四件事要区分开：

```java
int assigned;              // 声明：告诉 Java 有一个 int 变量
assigned = 5;              // 初始化：第一次赋值
System.out.println(assigned); // 读取：得到当前值 5
assigned = assigned + 2;   // 重新赋值：先算 5 + 2，再把 7 存回变量
System.out.println(assigned); // 再读取，得到 7
```

输出：

```text
5
7
```

第二次赋值不会回头修改已经打印到屏幕上的 `5`。屏幕输出是过去发生的结果；变量现在保存的是 `7`。

`int assigned = 5;` 是把声明和初始化写在同一行。变量声明后可以多次重新赋值，但不能在同一个作用域里重复声明同名局部变量：

```java
int assigned = 5;
assigned = 8;       // 正常：重新赋值
// int assigned = 9; // 错误：同一作用域重复声明
```

### 2.2 局部变量必须先初始化才能读取

方法内部声明的局部变量不会自动获得默认值：

```java
int remaining;
// System.out.println(remaining); // 编译错误：可能尚未初始化
remaining = 3;
System.out.println(remaining);   // 正常
```

Java 编译器会检查局部变量是否在每条可能执行到的路径上都已经赋值。这叫确定赋值检查。这样可以避免程序读取一个从未明确设置过的局部变量。

这条规则和类的字段不同：实例字段、静态字段在没有显式赋值时会有默认值，稍后会看到。

### 2.3 变量命名规则

变量名需要遵守语法规则，也应方便人阅读：

- 可以由字母、数字、下划线 `_`、美元符号 `$` 组成，但不能以数字开头。
- 不能使用 `class`、`int`、`return` 等 Java 关键字作为变量名。
- Java 区分大小写，`assigned` 和 `Assigned` 是两个不同名字。
- 常见变量采用小驼峰命名法：`finishedCount`、`remainingTasks`。
- 尽量使用能表达含义的名称，不要大量使用 `a`、`b`、`x1`。

例如：

```java
int finishedCount = 2;
int remainingTasks = 3;
boolean hasPending = true;
```

### 2.4 var：可以省略局部变量的类型书写，但不是动态类型

Java 10 开始支持 `var`，让编译器根据初始化表达式推断局部变量类型：

```java
var count = 5;          // 编译器推断为 int
var member = "小林";    // 编译器推断为 String
```

`var` 只是省略了类型书写，变量仍然有确定的静态类型：

```java
var count = 5;
// count = "五"; // 编译错误，count 仍然是 int
```

`var` 只能用于有初始化表达式的局部变量，不能用来声明字段、方法参数或方法返回类型。初学时建议先显式写类型，等能判断类型后再使用 `var` 提高可读性。

## 3　变量能保存什么：Java 的数据类型

Java 是静态类型语言。变量声明时要确定类型，之后不能随意把另一种不兼容的值赋给它。

Java 类型分为两大类：**基本类型（primitive types）**和**引用类型（reference types）**。

### 3.1 八种基本数据类型

| 分类  | 类型        | 大小 / 范围或特点                                                    | 示例与常见用途                                         |
| --- | --------- | ------------------------------------------------------------- | ----------------------------------------------- |
| 整数  | `byte`    | 8 位，有符号，-128～127                                              | `byte level = 3;`，明确需要小整数范围时使用                  |
| 整数  | `short`   | 16 位，有符号，-32768～32767                                         | `short offset = 300;`，普通业务计数通常直接用 `int`         |
| 整数  | `int`     | 32 位，有符号，-2,147,483,648～2,147,483,647                         | `int assigned = 5;`，最常见的普通整数类型                  |
| 整数  | `long`    | 64 位，有符号，-9,223,372,036,854,775,808～9,223,372,036,854,775,807 | `long total = 3_000_000_000L;`，数量可能超过 `int` 时使用 |
| 浮点  | `float`   | 32 位，约 6～7 位十进制有效数字                                           | `float ratio = 0.75F;`，明确需要单精度时使用               |
| 浮点  | `double`  | 64 位，约 15～16 位十进制有效数字                                         | `double height = 175.5;`，普通小数计算的常见选择            |
| 字符  | `char`    | 16 位 UTF-16 代码单元                                              | `char grade = 'A';`，单个字符代码单元，不是任意长度文本           |
| 布尔  | `boolean` | 只有 `true` 或 `false`                                           | `boolean done = false;`，条件判断的结果                 |

**怎么选类型？** 普通计数优先考虑 `int`；可能超过 `int` 范围的计数使用 `long`；一般小数计算用 `double`；真假判断用 `boolean`；一段文字用 `String`。不要为了“看起来更精确”就把所有数字都定义成 `long` 或 `double`，要根据数据含义和范围选择。

### 3.2 整数为什么有 byte、short、int、long？

它们都是整数，差别主要在可表示的范围。位数越多，能表示的整数范围越大。`int` 是 32 位有符号整数，`long` 是 64 位有符号整数。

整数也有边界。`int` 超出最大值后不会自动变成 `long`，而是发生整数溢出：

```java
int max = Integer.MAX_VALUE;
System.out.println(max);
System.out.println(max + 1);
```

第二行会得到一个负数，而不是自动扩容。因为表达式仍然按 `int` 运算。若业务数据可能超过 `int`，应该从一开始就选择 `long`，而不是等溢出后再补救。

### 3.3 float 和 double：能保存小数，但属于近似表示

```java
float hours = 1.5F;
double priceRate = 0.1;
```

注意：Java 中带小数点的浮点数字面量默认是 `double`。如果要赋给 `float`，通常需要在字面量后面加 `F` 或 `f`。长整数字面量通常加 `L`，例如 `3_000_000_000L`。数字中的下划线只是为了阅读方便，不改变数值。

浮点数使用二进制近似表示，并不是所有十进制小数都能精确表示：

```java
double a = 0.1;
double b = 0.2;
System.out.println(a + b);
```

常见输出是：

```text
0.30000000000000004
```

这不是 Java 算错，而是二进制浮点数的表示限制。对于图形、测量、科学计算等可以接受误差的场景，`double` 很常见；对于要求十进制精确的金额计算，通常使用 `BigDecimal`，或者在规则允许时用整数保存最小货币单位。

```java
import java.math.BigDecimal;

BigDecimal price = new BigDecimal("19.99");
BigDecimal tax = new BigDecimal("0.10");
BigDecimal total = price.add(tax);
System.out.println(total); // 20.09
```

这里 `BigDecimal` 是一个类，不是第九种基本类型。创建时推荐传入字符串，避免先经过 `double` 的近似值。它不能直接使用 `+`、`-`、`*`、`/`，需要调用 `add`、`subtract`、`multiply`、`divide` 等方法。除法遇到无限小数时还需要指定精度和舍入规则，后续业务章节再深入。

### 3.4 char、String 和 boolean

```java
char grade = 'A';
String memberName = "小林";
boolean hasPending = true;
```

- `char` 用单引号，保存一个 UTF-16 代码单元。某些补充平面字符（例如部分 emoji）需要两个 `char` 才能表示完整字符。
- `String` 用双引号，保存一段文本。它是引用类型，不是基本类型。
- `boolean` 只有 `true` 和 `false`，不能把 `0`、`1` 当作真假值，也不能写成字符串 `"true"`。

下面四种写法含义不同：

```java
3       // 整数
'3'     // 字符
"3"    // 字符串
"age"  // 文本 age，不是变量 age
```

## 4　表达式和运算：程序怎样算出结果

表达式是能够计算出一个值的代码片段。变量、字面量和运算组合起来就能形成表达式：

```java
int assigned = 5;
int finished = 2;
int remaining = assigned - finished;
```

第三行先读取 `assigned` 和 `finished`，计算 `5 - 2`，再把结果 `3` 赋给 `remaining`。

### 4.1 常见算术运算符

| 运算符 | 含义 | 示例 | 结果 |
| --- | --- | --- | --- |
| `+` | 加法 | `5 + 2` | `7` |
| `-` | 减法 | `5 - 2` | `3` |
| `*` | 乘法 | `5 * 2` | `10` |
| `/` | 除法 | `5 / 2` | `2`（整数除法） |
| `%` | 取余 | `5 % 2` | `1` |

**整数除法会丢弃小数部分，不是四舍五入。**

```java
System.out.println(5 / 2);     // 2
System.out.println(5.0 / 2);   // 2.5
System.out.println(5 / 2.0);   // 2.5
```

只要参与运算的操作数中有一个是浮点类型，运算就可能按浮点规则进行。不要把 `5 / 2` 的结果当成 `2.5` 再交给打印方法；小数在运算阶段就已经被截掉了。

### 4.2 运算优先级与括号

乘除和取余通常先于加减执行；括号可以明确表达你想要的顺序：

```java
int result1 = 2 + 3 * 4;     // 14
int result2 = (2 + 3) * 4;   // 20
```

业务代码优先写清晰的括号，不要让读代码的人靠背优先级猜意思。

### 4.3 字符串拼接

`+` 两侧只要有一侧是字符串，就会参与字符串拼接：

```java
System.out.println("剩余 " + 1 + 2);       // 剩余 12
System.out.println("剩余 " + (1 + 2));     // 剩余 3
```

第一行从左往右计算：先得到文本 `"剩余 1"`，再拼上 `2`。第二行先算括号里的整数加法。初学时建议先把数字计算完成，再拼接输出文本。

现在把前面的内容合成一个完整文件。将它保存为 `TaskSummary.java`，替换之前的最小示例：

```java
class TaskSummary {
    public static void main(String[] args) {
        String member = "小林";
        int assigned = 5;
        int finished = 2;
        int remaining = assigned - finished;

        System.out.println(member + "：剩余 " + remaining + " 项");
    }
}
```

执行 `java TaskSummary.java`，预期输出 `小林：剩余 3 项`。只把 `finished` 从 2 改成 4，再运行，结果应为 `小林：剩余 1 项`。这说明程序是根据输入数据计算结果，而不是把答案写死在输出语句中。

## 5　类型转换：为什么有时能直接赋值，有时必须强制转换？

变量有明确类型。把一个值赋给另一种类型的变量时，Java 会检查类型是否兼容。

### 5.1 自动类型转换（扩大转换）

较小范围的整数可以自动转换为较大范围的整数；整数也可以自动转换为浮点类型：

```java
int count = 5;
long total = count;
double average = count;
```

`count` 本身仍然是 `int`，赋值时转换出来的值分别存入 `long` 和 `double` 变量。自动转换不代表所有信息都绝对不会损失，例如 `long` 转 `double` 在极大数值下也可能失去整数精度。

### 5.2 强制类型转换（缩小转换）

可能丢失信息的转换通常需要明确写出目标类型：

```java
double score = 98.8;
int wholeScore = (int) score;
System.out.println(wholeScore); // 98
```

`(int)` 是强制类型转换。浮点数转整数会直接截去小数部分，不是四舍五入。如果业务要求四舍五入，应使用明确的舍入方法，而不是误以为强转会自动取整。

### 5.3 转换和运算结果类型不是一回事

```java
byte a = 10;
byte b = 20;
// byte c = a + b; // 编译错误
int c = a + b;      // 正常
```

`byte`、`short`、`char` 在多数算术运算中会先提升为 `int`，所以 `a + b` 的结果类型是 `int`。这也是为什么不能把结果直接放进 `byte`，除非明确强制转换并确认范围安全。

## 6　引用类型与 null：变量不一定直接保存对象内容

基本类型变量直接保存对应类型的值。引用类型变量保存的是对象引用，可以理解为“通过它找到某个对象的方式”。

```java
String first = "小林";
String second = first;
```

这里 `first` 和 `second` 都能访问同一个字符串对象。对于自定义对象，两个引用也可能指向同一个实例；通过一个引用修改对象内部状态，另一个引用访问时也会看到变化。对象与引用的完整机制会在第 03 节展开。

引用变量还可能是 `null`：

```java
String name = null;
System.out.println(name); // null
```

`null` 表示当前没有引用任何对象。它和空字符串 `""` 不一样：空字符串是一个长度为 0 的字符串对象，`null` 则没有可访问的字符串对象。对 `null` 调用方法会产生 `NullPointerException`。

### 6.1 String 的一个重要特点：不可变

`String` 对象创建后，字符串内容不能原地修改。看起来像“修改字符串”的操作，实际会产生新的字符串结果：

```java
String name = "小林";
name = name + "同学";
System.out.println(name); // 小林同学
```

这里变量 `name` 改为引用拼接后的新字符串，不是把原来的字符串对象内部改掉。字符串比较内容时通常使用 `equals`，而不是用 ` == ` 判断内容是否相同：

```java
String a = new String("Java");
String b = new String("Java");
System.out.println(a == b);      // false：比较是否为同一个对象引用
System.out.println(a.equals(b)); // true：比较字符串内容
```

` == ` 对引用类型比较的是引用是否相同；`equals` 的具体含义由类实现。这个区别在后续集合和对象比较章节会继续学习。

## 7　变量写在哪里：作用域与数据归属

**作用域**回答“在哪段代码里可以使用这个名字”；**归属**回答“这个数据属于一次方法调用、某个对象，还是整个类”。先认识四种常见位置：

| 写在哪里 | 名称 | 初始值和归属 |
| --- | --- | --- |
| 方法或代码块内部 | 局部变量 | 必须先明确赋值才能读取；只在所在作用域内可见 |
| 方法参数括号中 | 参数 | 调用时由传入的实参初始化；属于这次调用 |
| 类中、方法外、没有 `static` | 实例字段 | 每个对象各有一份；字段有默认值 |
| 类中、方法外、带 `static` | 静态字段（类变量） | 同一个类共享一份；字段有默认值 |

下面的完整程序把四种位置放在一起。新建 `MemberDemo.java`：

```java
class MemberDemo {
    String name;                         // 实例字段：每个对象各自拥有
    static String team = "后端组";       // 静态字段：所有对象共享

    void report(int assigned) {          // assigned 是方法参数
        int remaining = assigned - 1;    // remaining 是局部变量
        System.out.println(name + " / " + team + " / " + remaining);
    }

    public static void main(String[] args) {
        MemberDemo first = new MemberDemo();
        MemberDemo second = new MemberDemo();
        first.name = "小林";
        second.name = "小周";

        first.report(5);
        MemberDemo.team = "平台组";
        second.report(3);
        first.report(5);
    }
}
```

执行：

```powershell
java MemberDemo.java
```

预期输出：

```text
小林 / 后端组 / 4
小周 / 平台组 / 2
小林 / 平台组 / 4
```

第一次调用时，`assigned` 接收 5，`remaining` 计算为 4。`name` 读取当前调用对象的实例字段，`team` 读取类共享的静态字段。修改 `first.name` 只影响第一个对象；修改 `MemberDemo.team` 会影响所有对象读取到的团队名称。

字段默认值与局部变量不同：数值字段默认为 0，`boolean` 字段默认为 `false`，`char` 字段默认为 `\u0000`，引用类型字段默认为 `null`。局部变量没有这些默认值，必须先初始化。

> 本节只建立变量位置的初步概念。对象引用、`static`、封装和字段访问会在 [[20-后端/Java/03-类对象与列表|第 03 节：类、对象与面向对象基础]] 系统展开。

## 8　输出不只是 println：格式化输出

简单输出可以使用 `print` 和 `println`。需要控制格式时，可以使用 `printf`：

```java
String member = "小林";
int remaining = 3;
double completionRate = 0.875;

System.out.printf("成员：%s，剩余：%d 项，完成率：%.1f%%%n",
        member, remaining, completionRate * 100);
```

输出：

```text
成员：小林，剩余：3 项，完成率：87.5%
```

常见占位符：

| 占位符 | 含义 | 常见对应值 |
| --- | --- | --- |
| `%s` | 字符串形式 | `String` 或其他对象 |
| `%d` | 十进制整数 | `int`、`long` |
| `%f` | 浮点数 | `float`、`double` |
| `%.2f` | 保留两位小数显示 | 浮点数 |
| `%n` | 平台对应的换行符 | 无需传值 |
| `%%` | 输出百分号本身 | 无需传值 |

格式化输出只控制显示方式，不会改变变量本身的精度或值。例如 `%.2f` 只是把数字按两位小数格式显示，不等于把原变量永久四舍五入到两位。

## 9　常见错误：一次只制造一个问题

回到 `TaskSummary.java`，每次只改一处，保存并重新运行：

| 故意改动 | 观察到的现象 | 原因 |
| --- | --- | --- |
| `int finished = "2";` | 编译报类型不兼容 | 右侧是字符串，左侧要求整数 |
| 把 `remaining` 改为 `Remaining` | 找不到变量 | Java 区分大小写 |
| 删除局部变量初始化后直接打印 | 编译报可能未初始化 | 局部变量必须确定赋值 |
| 把 `5 / 2` 当成小数除法 | 输出 `2` | 两边都是整数，执行整数除法 |
| 对 `null` 字符串调用 `length()` | 运行时抛 `NullPointerException` | 引用没有指向对象 |
| 把减号换成加号 | 程序正常运行但结果不符合业务 | 语法正确不代表业务逻辑正确 |

要区分三种情况：**编译错误**表示源码不符合语言规则，程序还没开始执行；**运行时异常**表示程序已经运行到某处，但发生了无法正常完成的情况；**逻辑错误**表示程序能运行，却算出了错误答案。
