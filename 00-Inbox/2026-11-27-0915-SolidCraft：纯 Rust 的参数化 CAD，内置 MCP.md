# SolidCraft：纯 Rust 的参数化 CAD，内置 MCP

## 内容

`sudo snap install solidcraft`（Mac/Windows 也有安装包）；改一个尺寸，特征树自动重建，Agent 可通过内置 MCP 服务器直接建模。适合把支架、外壳、治具这类重复结构件的设计交给脚本和 agent，省掉手工改图。 [GitHub](https://github.com/tangency-labs/solidcraft)

## 怎么用

在日报里点开原文，按项目文档安装/试用；先在一个小工作流验证，再决定是否接入。
