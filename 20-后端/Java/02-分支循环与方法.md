# 第 02 节　分支、循环与方法：统计还有几名成员有待办

上一节已经能算出一个人的剩余任务数。现在有三名成员，分别剩下 `3、0、2` 项。问题变成：**有待办的人数是多少？** 答案是 2，不是任务总数 5。

本节会把一个计算逐步扩展成一段可重复使用的程序。学完后，你应该能够：

- 用 `if`、`else if`、`else` 和 `switch` 控制执行路径。
- 用数组保存一组同类型的数据，并理解下标和固定长度。
- 使用 `for`、增强 `for`、`while` 和 `do...while` 重复处理数据。
- 使用计数器和累加器完成统计。
- 定义方法，通过参数接收输入，通过 `return` 返回结果。
- 理解方法重载、局部变量作用域，以及 Java 的值传递规则。

本节示例都使用 JDK 21 和 PowerShell 的源码启动模式。代码块会根据内容说明放置位置：普通语句片段放在 `main` 方法内；方法声明放在类体中、与 `main` 并列；标注“完整文件”的代码则可以直接保存运行。不要把方法声明嵌套写进 `main`，也不要把多个实验不加区分地重复追加到同一个位置。

## 先认清四个问题，不把四种写法一起背

| 遇到的问题 | 用什么解决 | 它不负责什么 |
| --- | --- | --- |
| 怎样判断一个人是否算入统计？ | 条件表达式产生 `true` 或 `false`，`if` 决定执行哪段代码 | 不负责自动换到下一个人 |
| 三个人的数量放在哪里？ | `int[]` 按顺序保存多个整数 | 数组本身不会统计 |
| 怎样对每个人做同一件事？ | 循环重复执行代码，每轮处理一个元素 | 循环不会自动记住统计结果 |
| 换一组人还要重复写循环吗？ | 方法用参数接收不同输入，用返回值交出答案 | 返回值不是打印结果 |

## 1　先判断一个人，不要急着写循环

新建完整文件 `PendingCount.java`：

```java
class PendingCount {
    public static void main(String[] args) {
        int remaining = 3;
        boolean hasPending = remaining > 0;
        System.out.println(hasPending);
    }
}
```

运行：

```powershell
java PendingCount.java
```

输出 `true`。把 `3` 改成 `0`，输出变成 `false`。`remaining > 0` 是一个比较表达式，比较结果的类型是 `boolean`。

### 1.1 比较运算符

| 运算符 | 含义 | 示例 | 结果 |
| --- | --- | --- | --- |
| `>` | 大于 | `3 > 0` | `true` |
| `<` | 小于 | `0 < 3` | `true` |
| `>=` | 大于或等于 | `2 >= 2` | `true` |
| `<=` | 小于或等于 | `2 <= 1` | `false` |
| `==` | 等于 | `2 == 2` | `true` |
| `!=` | 不等于 | `2 != 3` | `true` |

不要把 `=` 和 `==` 混淆：`=` 是赋值，`==` 是比较是否相等。Java 的条件必须是 `boolean`，不会像 JavaScript/TypeScript 一样把数字 `3` 或空字符串自动当作真假值。

### 1.2 if、else 和 else if

把 `main` 中最后一行替换成：

```java
if (hasPending) {
    System.out.println("有待办");
} else {
    System.out.println("已清空");
}
```

`if` 后面圆括号内必须是布尔表达式。条件为 `true` 时执行第一个代码块，为 `false` 时执行 `else` 代码块。

需要多个互斥分支时，可以使用 `else if`：

```java
if (remaining > 0) {
    System.out.println("有待办");
} else if (remaining == 0) {
    System.out.println("已清空");
} else {
    System.out.println("数据不合法");
}
```

分支按从上到下的顺序判断，命中第一个条件后执行对应代码块，后面的分支不再判断。这里最后一个 `else` 负责处理前面条件都不成立的情况。

### 1.3 逻辑运算符：组合多个条件

```java
int remaining = 3;
boolean isActive = true;

boolean canReceive = remaining > 0 && isActive;
boolean needsAttention = remaining == 0 || !isActive;
```

| 运算符 | 含义 | 示例 |
| --- | --- | --- |
| `&&` | 逻辑与，左右都为真才为真 | `remaining > 0 && isActive` |
| `||` | 逻辑或，任意一边为真就为真 | `remaining == 0 || !isActive` |
| `!` | 逻辑非，反转真假 | `!isActive` |

`&&` 和 `||` 具有短路特性：对于 `A && B`，如果 A 已经是 `false`，B 不会再计算；对于 `A || B`，如果 A 已经是 `true`，B 不会再计算。它们常用于先检查对象是否存在，再访问对象属性：

```java
String name = null;
if (name != null && name.length() > 0) {
    System.out.println(name);
}
```

左边先判断 `name != null`。当它为 `false` 时，右边不会执行，因此不会因为调用 `length()` 而触发空指针异常。

## 2　多种固定选项：switch

如果根据一个变量的明确取值选择不同操作，`switch` 通常比连续写多个 `else if` 更清楚：

```java
int status = 2;

switch (status) {
    case 1 -> System.out.println("待处理");
    case 2 -> System.out.println("进行中");
    case 3 -> System.out.println("已完成");
    default -> System.out.println("未知状态");
}
```

这里使用的是现代 Java 的箭头写法。`status` 为 2 时只执行对应分支。`default` 类似兜底分支。传统 `case:` 写法需要留意 `break`，否则可能发生贯穿执行；本课程先使用箭头写法，避免把两套规则混在一起。

## 3　把一组数放在一起：数组

如果有三个成员，就可以声明三个变量，但人数变化时会很难维护。数组可以把多个相同类型的值放在一个变量中。

把 `main` 中内容换成：

```java
int[] remaining = {3, 0, 2};
System.out.println(remaining.length);
System.out.println(remaining[0]);
System.out.println(remaining[1]);
System.out.println(remaining[2]);
```

输出：

```text
3
3
0
2
```

### 3.1 数组声明和创建

`int[] remaining` 表示变量 `remaining` 的类型是“整数数组”。常见创建方式：

```java
int[] first = {3, 0, 2};       // 声明并用已有元素初始化
int[] second = new int[3];     // 创建长度为 3 的整数数组
```

第二种写法会创建一个长度为 3 的数组，元素先使用类型对应的默认值初始化。`int` 数组元素默认为 0，所以 `second` 的三个元素初始都是 0。

数组是引用类型。`new int[3]` 创建数组对象，变量保存对数组的引用。数组创建后长度固定，不能像 JavaScript 数组那样直接 `push` 增加长度。需要动态增删元素时，后续会使用 `List`。

### 3.2 下标从 0 开始

数组第一个元素的下标是 0。长度为 3 的数组有效下标是 0、1、2，不存在下标 3。

```java
int[] values = {3, 0, 2};
System.out.println(values[0]); // 3
System.out.println(values[2]); // 2
// System.out.println(values[3]); // 运行时越界异常
```

`values.length` 是数组长度，不是最后一个下标。最后一个下标通常是 `values.length - 1`。

数组下标越界会抛出 `ArrayIndexOutOfBoundsException`。这类错误通常不是编译错误，因为编译器无法仅凭代码确定运行时下标一定在范围内。

## 4　循环：让程序重复处理每个成员

### 4.1 增强 for：只关心每个元素

保留数组声明，把后面的代码替换为：

```java
for (int amount : remaining) {
    System.out.println(amount);
}
```

输出三行 `3`、`0`、`2`。增强 `for` 可以读作：从 `remaining` 中依次取出一个元素，放到变量 `amount` 中，然后执行循环体。它适合只关心元素值、不需要下标的情况，类似 TypeScript 的 `for...of`。

### 4.2 普通 for：需要下标或控制遍历位置

```java
for (int index = 0; index < remaining.length; index++) {
    System.out.println("第 " + (index + 1) + " 位成员剩余 " + remaining[index] + " 项");
}
```

普通 `for` 的三个部分：

```java
for (初始化; 继续条件; 每轮结束后的操作) {
    // 循环体
}
```

执行顺序是：先初始化一次；判断条件；条件为真时执行循环体；执行更新表达式；再判断条件。条件为假时结束。

### 4.3 while：只知道继续条件

```java
int remainingTasks = 3;
while (remainingTasks > 0) {
    System.out.println("处理一项任务");
    remainingTasks--;
}
```

`while` 先判断条件，再决定是否进入循环。条件一开始就是 `false` 时，循环体一次也不执行。一定要确认循环过程中有机会让条件变成 `false`，否则可能陷入无限循环。

### 4.4 do...while：至少执行一次

```java
int attempts = 0;
do {
    attempts++;
    System.out.println("尝试次数：" + attempts);
} while (attempts < 1);
```

`do...while` 先执行循环体，再判断条件，因此至少执行一次。末尾的 `while (...)` 后面需要分号。对于遍历数组这种可能为空的场景，通常使用 `for`，因为空数组应当执行零次。

### 4.5 break 和 continue

- `break`：立即结束当前循环。
- `continue`：结束本轮剩余部分，进入下一轮。

例如，只打印第一个大于零的数量：

```java
for (int amount : remaining) {
    if (amount > 0) {
        System.out.println(amount);
        break;
    }
}
```

跳过没有待办的成员：

```java
for (int amount : remaining) {
    if (amount == 0) {
        continue;
    }
    System.out.println(amount);
}
```

不要为了少写几行代码而滥用 `break` 和 `continue`。如果简单的 `if` 已经足够，直接写清楚通常更容易维护。

## 5　计数器和累加器：循环如何记住结果

现在统计“有待办的人数”，不是“所有任务的总数”。保留数组声明，使用：

```java
int count = 0;
for (int amount : remaining) {
    if (amount > 0) {
        count = count + 1;
    }
}
System.out.println(count);
```

输出 `2`。

| 本轮取到的值 | `amount > 0` | 本轮前的 count | 本轮后的 count |
| --- | --- | ---: | ---: |
| 3 | true | 0 | 1 |
| 0 | false | 1 | 1 |
| 2 | true | 1 | 2 |

`count` 是计数器：每遇到一个符合条件的成员就加 1。它在循环外初始化一次，循环每轮继续沿用上一次的结果。

如果要统计任务总数，逻辑就不同：

```java
int total = 0;
for (int amount : remaining) {
    total = total + amount;
}
System.out.println(total); // 5
```

`total` 是累加器，每轮加上当前元素的数量。计数器和累加器不要混淆：一个加“符合条件的个数”，一个加“元素本身的数值”。

还可以在循环中找最大值。对于非空数组：

```java
int max = remaining[0];
for (int amount : remaining) {
    if (amount > max) {
        max = amount;
    }
}
System.out.println(max); // 3
```

这里先把最大值设成第一个元素，避免随意把 0 当作最大值导致全是负数时出错。若数组可能为空，必须先处理空数组，再访问 `remaining[0]`。

## 6　方法：给一段可重复使用的计算起名字

如果统计逻辑要对很多组成员重复执行，不应该复制整段循环。可以把它定义成方法。下面的 `countPending` 是**类成员方法声明片段**，应该放在 `class PendingCount { ... }` 的类体内，与 `main` 方法并列，不能放进 `main` 的花括号里。

方法声明的一般结构：

```java
返回值类型 方法名(参数列表) {
    // 方法体
    return 返回值;
}
```

例如：

```java
static int countPending(int[] amounts) {
    int count = 0;
    for (int amount : amounts) {
        if (amount > 0) {
            count++;
        }
    }
    return count;
}
```

逐项理解：

- `static`：这是静态方法，可以通过类名调用；本节 `main` 也是静态方法，因此可以直接调用它。实例方法和静态方法的区别会在第 03 节详细学习。
- `int`：返回值类型，表示方法执行完成后交回一个整数。
- `countPending`：方法名。
- `int[] amounts`：参数，表示调用者需要传入一个整数数组。
- `{ ... }`：方法体，放具体计算过程。
- `return count`：把结果交还给调用者，并结束这次方法执行。

### 6.1 参数、实参和返回值

调用方法：

```java
int[] remaining = {3, 0, 2};
int pendingMembers = countPending(remaining);
System.out.println(pendingMembers);
```

- **形参（parameter）**：方法声明中的 `int[] amounts`，是方法内部使用的名字。
- **实参（argument）**：调用处传入的 `remaining`。
- **返回值（return value）**：方法执行后交还的 `count`。

调用处的变量名和形参名不需要相同。调用时把值传进去，方法体通过形参名使用它。

### 6.2 return 和 void

下面两段仍然是类成员方法声明，放在类体中，与 `main` 并列。有返回值的方法必须在所有正常结束路径上交回匹配类型的值：

```java
static int add(int a, int b) {
    return a + b;
}
```

`void` 表示方法不向调用者交回业务结果：

```java
static void printMember(String name) {
    System.out.println("成员：" + name);
}
```

`return;` 可以提前结束一个 `void` 方法。不要把“方法打印了内容”和“方法返回了内容”混为一谈：打印是向控制台输出，返回是把值交给调用处。

### 6.3 方法调用时会发生什么

执行 `countPending(remaining)` 时，可以按下面的顺序理解：

1. 程序先计算实参表达式，得到数组引用。
2. 进入 `countPending` 方法，为这次调用创建参数和局部变量。
3. 循环读取数组元素，更新局部计数器 `count`。
4. 执行 `return count`，把整数结果交还调用处。
5. 调用处继续执行，把返回值赋给 `pendingMembers`。

每次调用方法，都会有自己的一组局部变量。方法执行结束后，这次调用的局部变量就不能再从外部直接访问。

## 7　方法重载：同一个方法名可以有不同参数列表

Java 允许在同一个类中定义多个同名方法，只要参数列表不同。这叫方法重载（Overload）：

```java
static int countPending(int[] amounts) {
    int count = 0;
    for (int amount : amounts) {
        if (amount > 0) count++;
    }
    return count;
}

static int countAtLeast(int[] amounts, int threshold) {
    int count = 0;
    for (int amount : amounts) {
        if (amount >= threshold) count++;
    }
    return count;
}
```

这里方法名不同，不是重载。真正的重载示例是同一个 `printValue` 接受不同类型的参数：

```java
static void printValue(int value) {
    System.out.println("整数：" + value);
}

static void printValue(String value) {
    System.out.println("文本：" + value);
}
```

调用 `printValue(5)` 会选择 `int` 版本，调用 `printValue("五")` 会选择 `String` 版本。

**重载依据是方法名和参数列表，不是返回值类型。** 参数列表看参数的数量、类型和顺序，不看参数变量名。只把一个方法的返回类型从 `int` 改成 `long`，或者只把参数名从 `a` 改成 `value`，但方法名和参数类型顺序完全相同，都不能构成重载。

## 8　Java 的参数传递：始终是值传递

下面的 `changeNumber`、`changeFirst` 和 `replaceArray` 是类成员方法；示例中的 `main` 也是类成员方法。把它们放在同一个类中，彼此并列，不要嵌套在另一个方法里。

这一点很容易与“对象是引用类型”混在一起。Java 方法调用时始终传递参数值：

- 基本类型参数：复制基本类型的值。
- 引用类型参数：复制引用的值。方法参数和调用者变量会指向同一个对象，但参数变量本身是另一份引用副本。

先看基本类型：

```java
static void changeNumber(int value) {
    value = 100;
}

public static void main(String[] args) {
    int number = 5;
    changeNumber(number);
    System.out.println(number); // 5
}
```

方法里把参数 `value` 改成 100，不会改变调用者的 `number`，因为传进去的是数值副本。

再看数组：

```java
static void changeFirst(int[] values) {
    values[0] = 100;
}

public static void main(String[] args) {
    int[] numbers = {1, 2, 3};
    changeFirst(numbers);
    System.out.println(numbers[0]); // 100
}
```

参数 `values` 保存的是引用副本，但它与 `numbers` 指向同一个数组对象，所以通过参数修改数组元素，调用者也能看到变化。

如果在方法里重新给参数赋一个新数组：

```java
static void replaceArray(int[] values) {
    values = new int[]{9, 9, 9};
}
```

调用者的 `numbers` 不会因此改为指向新数组。因为改变的是方法参数自己的引用副本，而不是调用者变量本身。

记住：**Java 没有 C# 那种默认按引用传递的参数机制；对象引用作为一个值被复制传入。**

## 9　把所有知识串起来：完整程序

下面是本节最终的完整 `PendingCount.java`。它统计有待办的成员数量、任务总数，以及达到门槛的人数：

```java
class PendingCount {
    public static void main(String[] args) {
        int[] remaining = {3, 0, 2};

        System.out.println("有待办的成员：" + countPending(remaining));
        System.out.println("任务总数：" + sumTasks(remaining));
        System.out.println("至少有 2 项的成员：" + countAtLeast(remaining, 2));
    }

    static int countPending(int[] amounts) {
        int count = 0;
        for (int amount : amounts) {
            if (amount > 0) {
                count++;
            }
        }
        return count;
    }

    static int sumTasks(int[] amounts) {
        int total = 0;
        for (int amount : amounts) {
            total += amount;
        }
        return total;
    }

    static int countAtLeast(int[] amounts, int threshold) {
        int count = 0;
        for (int amount : amounts) {
            if (amount >= threshold) {
                count++;
            }
        }
        return count;
    }
}
```

运行：

```powershell
java PendingCount.java
```

预期输出：

```text
有待办的成员：2
任务总数：5
至少有 2 项的成员：2
```

注意三个方法的职责不同：`countPending` 数成员，`sumTasks` 加任务数量，`countAtLeast` 按门槛统计成员。它们复用了循环结构，但每个方法只回答一个明确问题。

## 10　常见错误与定位方式

| 问题 | 常见表现 | 原因与检查方式 |
| --- | --- | --- |
| `if (remaining)` | 编译错误 | Java 条件必须是 `boolean`，应写成 `remaining > 0` |
| `remaining[3]` | 运行时数组越界 | 长度为 3 的数组有效下标只有 0、1、2 |
| `while` 条件永远为真 | 程序一直运行 | 检查循环体有没有更新条件依赖的变量 |
| 在方法里声明另一个普通方法 | 编译错误 | Java 普通方法需要定义在类体中，不能嵌套定义在另一个方法体内 |
| 有返回类型但没有 return | 编译错误 | 所有正常结束路径都必须返回匹配类型的值 |
| 把 `return` 当作打印 | 看不到控制台输出 | `return` 把结果交给调用者，需由调用者打印 |
| 只改返回类型想重载 | 编译错误 | 重载必须改变参数列表，返回类型不参与区分 |
| 认为 Java 对象参数是按引用传递 | 修改参数变量后误以为调用者变量也改变 | Java 传递的是引用值的副本；修改对象状态与重新给参数赋值不同 |

## 11　独立练习

### 练习一：统计达到门槛的成员
