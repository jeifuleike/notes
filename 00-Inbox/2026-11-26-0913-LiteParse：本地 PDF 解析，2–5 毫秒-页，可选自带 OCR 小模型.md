# LiteParse：本地 PDF 解析，2–5 毫秒/页，可选自带 OCR 小模型

## 内容

`pip install liteparse` 后 `lit models pull ocria-nano`。输出带坐标的 Markdown/JSON，扫描件交给 8.1M 参数的 CPU OCR 处理；适合把合同、发票、报告批量转成能喂给 RAG 或 agent 的干净文本，全程不出本机。 [GitHub](https://github.com/run-llama/liteparse)

## 怎么用

在日报里点开原文，按项目文档安装/试用；先在一个小工作流验证，再决定是否接入。

## 优化什么工作

工具调研、信息筛选和日常工作流自动化。
