| **类型** | LLM应用开发平台（含Agent能力） |
| **Stars** | 70,000+ |
| **官网** | https://dify.ai |

### 简介

Dify 是最流行的开源 LLM 应用开发平台，提供可视化 AI 工作流编排、RAG 管道构建和 Agent 策略配置。2026年推出 Agent 2.0 架构，支持更复杂的推理循环和多Agent协作。

### 核心特点

1. **可视化工作流** — 拖拽式编排，条件分支、循环、并行处理
2. **RAG 全链路** — 文档摄取 → 向量化 → 多路检索 → 重排序
3. **Agent 策略** — ReAct、Function Call、多Agent协作开箱即用
4. **多模型支持** — 100+ LLM 提供商（OpenAI、Anthropic、开源模型等）
5. **企业功能** — SSO、RBAC、审计日志、API 管理、私有部署

### 为什么热门

- 「可视化+开源+自部署」精准击中企业隐私和数据安全需求
- 全链路覆盖（应用构建→工作流→Agent→监控→运营），用户粘性极高
- 开发者生态活跃，插件和模板市场快速增长

### 产品启示

- 可视化+Agent 是降低使用门槛的关键路径
- 企业级功能（RBAC/审计/私有部署）是商业化的护城河
- RAG + Agent 融合是确定性方向

|------|------|

| **类型** | Agent 编排框架（状态图驱动） |
| **Stars** | 45,000+ |
| **官网** | https://langchain.com/langgraph |

### 简介

LangGraph 是 LangChain 生态中的 Agent 编排框架，采用有向状态图（StateGraph）构建复杂多步 Agent 工作流。支持循环、条件分支、人机协作和检查点持久化。2026年已从 LangChain 独立发展为最主流的 Agent 编排标准之一。

### 核心特点

1. **状态图驱动** — StateGraph 定义完整状态机，支持检查点持久化和回放
2. **人机协作** — `interrupt` 机制在关键节点暂停等待人工审批
3. **多 Agent 编排** — 子图嵌套实现层级 Agent 协作
4. **流式输出** — Token 级 streaming，实时观测 Agent 决策过程
5. **LangSmith 集成** — 强大的调试、追踪和评估平台

### 为什么热门

- LangChain 庞大用户基础带来自然迁移路径
- 图编排模型比链式模型灵活得多，适合复杂 Agent 场景
- 企业级特性（持久化、人机协作）适合生产环境

### 产品启示

- 状态图是 Agent 编排的核心抽象，值得深入借鉴
- 持久化 + 可恢复是生产级 Agent 的基本要求
- 可视化监控是 Agent 产品差异化的重要维度

## 🎯 产品设计启示（供产品编写员/原型组参考）

### 1. 明确的产品形态选择

当前市场上的 AI Agent 产品主要分为三类：

- **框架型**（LangGraph, CrewAI, Agno）：面向开发者，提供 Agent 构建能力
- **平台型**（Dify, n8n）：面向技术用户和企业，提供可视化编排 + 部署
- **工具型**（Browser Use, Cline）：面向特定场景，专注单一能力

### 2. 成功产品的共性特征

1. **多 Agent 协作** — 复杂任务需要 Agent 团队而非单个 Agent
2. **工具生态** — Agent 的能力上限由工具决定
3. **可视化监控** — 用户需要看到 Agent 在做什么、为什么这样做
4. **人机协作（HITL）** — 关键决策保留人类审批
5. **企业级能力** — 私有部署、RBAC、审计是 B 端必备

### 3. 差异化机会

- **垂直场景 Agent** — 金融/医疗/法律等垂直领域 Agent 仍是蓝海
- **Agent 记忆系统** — 长期记忆和多会话连续性有差异空间
- **多模态 Agent** — 图像/视频/音频 Agent 尚未充分竞争
- **Agent 评测体系** — 如何衡量 Agent 做得好不好是待解决问题
- **轻量部署** — 面向个人和小团队的轻量 Agent 产品
