# 审计

## 运行

```powershell
python "D:\notes\90-知识系统\脚本\kb.py" doctor
python "D:\notes\90-知识系统\脚本\kb.py" lint
```

## 检查

- 配置和目录是否存在。
- 模板和 Skill 是否完整。
- 断链和重复标题。
- AI 卡是否有 `sources`、是否超过 100 行、是否过期。
- 工作流规范字段是否完整。
- Inbox 是否积压。
- `80-Skill库/00-索引.md` 是否与实际目录一致。

## 输出

按严重程度分组：错误、警告、建议。每条给出路径和修复方式。

## 约束

- 只报告，不自动修复。
- 不删除笔记。
- 不批量改写旧笔记的 frontmatter。
