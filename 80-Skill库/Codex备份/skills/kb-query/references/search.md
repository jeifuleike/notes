# 检索

## 命令

```powershell
python "D:\notes\90-知识系统\脚本\kb.py" search "关键词" --limit 10
python "D:\notes\90-知识系统\脚本\kb.py" search "关键词" --scope "20-后端" --json
```

## 排序

标题匹配权重最高，其次是标签、路径、标题层级和正文。中文查询会拆成短片段辅助匹配。

## 引用

- 使用 `路径:行号`。
- 引用原文时保持原意，不把推断写成原文。
- 多篇笔记冲突时并列展示，不擅自裁决。

## 范围
