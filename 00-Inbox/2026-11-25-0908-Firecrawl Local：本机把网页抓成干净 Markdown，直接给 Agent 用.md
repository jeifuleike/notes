# Firecrawl Local：本机把网页抓成干净 Markdown，直接给 Agent 用

## 内容

`cargo install firecrawl-local`，再运行 `firecrawl-local init` 自动注册到 Claude Code、Cursor、Codex 等；抓文档、竞品页和批量 URL 不用手工复制，数据不出本机。[GitHub](https://github.com/firecrawl/firecrawl)

## 怎么用

在日报里点开原文，按项目文档安装/试用；先在一个小工作流验证，再决定是否接入。

## 优化什么工作

工具调研、信息筛选和日常工作流自动化。
