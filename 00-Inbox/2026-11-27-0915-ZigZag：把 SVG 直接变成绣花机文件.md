# ZigZag：把 SVG 直接变成绣花机文件

## 内容

`brew install --cask simpsoka/zigzag/zigzag`（Mac；Windows/Linux 有安装包）；导入 SVG 后可视化调整针迹，导出 PES、DST、EXP、JEF、VP3，或经蓝牙直发 Brother Skitch。适合小批量布贴、样品和手作电商，省掉专用打版软件。 [GitHub](https://github.com/simpsoka/zigzag)
