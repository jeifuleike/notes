# last30days

## 内容

把 Reddit、X、YouTube、HN 的口碑汇成一份带引用的调研：`/plugin marketplace add mvanhorn/last30days-skill` 后 `/plugin install last30days`（或 `npx skills add mvanhorn/last30days-skill -g`）；给一个话题就并行搜多平台，按真实互动排序再综合。

## 怎么用

1. `/plugin marketplace add mvanhorn/last30days-skill`，再 `/plugin install last30days`（或 `npx skills add ... -g`）；2. 给一个话题；3. 得到按互动量排序、带引用的跨平台调研。

## 优化什么工作

做竞品或行业快速调研时，一次拉齐多平台的真实讨论并带引用，不用逐平台翻。
