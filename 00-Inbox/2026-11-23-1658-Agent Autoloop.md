# Agent Autoloop

## 内容

让 Claude Code、Codex 这类命令行 Agent 在后台自己接活，遇到拿不准的事把确认卡片推到钉钉、飞书、企微或 Slack。

## 怎么用

装好后在项目目录启动 `agent-autoloop`，把 Claude Code / Codex 接到它的事件源；Agent 在后台跑任务，需要你拍板时会在钉钉/飞书/企微发确认卡片，回复后它继续。

## 优化什么工作

优化“人必须守着终端等 Agent”的长任务流程：夜间跑重构、批量修 bug、定期巡检时不用一直盯着，确认点集中处理。
